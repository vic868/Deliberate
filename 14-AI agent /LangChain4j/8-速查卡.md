# LangChain4j 速查卡

> 一页纸。版本基线：`langchain4j 1.23.0` / starter `1.23.0-beta33` / JDK 17。
> 版本时间线与升级路径见 [[9-版本记录]]。

## 1. 依赖


## 2. 最小骨架

```java
// 模型
ChatModel model = OpenAiChatModel.builder()
        .baseUrl("https://api.deepseek.com/v1").apiKey(System.getenv("DEEPSEEK_API_KEY"))
        .modelName("deepseek-chat").temperature(0.3).maxRetries(2).timeout(Duration.ofSeconds(60))
        .build();

// 接口
interface Assistant {
    @SystemMessage("你是企业知识库助手") String chat(@MemoryId String uid, @UserMessage String q);
    @UserMessage("用 {{style}} 语气说：{{text}}") String rewrite(@V("text") String t, @V("style") String s);
    Ticket classify(String text);                 // 结构化
    TokenStream stream(String q);                 // 流式
}

// 装配
Assistant ai = AiServices.builder(Assistant.class)
        .chatModel(model)
        .streamingChatModel(streamingModel)
        .chatMemoryProvider(id -> MessageWindowChatMemory.builder().id(id).maxMessages(20).build())
        .tools(toolBeans...)
        .contentRetriever(retriever)
        .inputGuardrails(new PromptInjectionGuardrail())
        .maxToolCallingRoundTrips(5)
        .afterToolExecution(e -> log.info("{} {}", e.request().name(), e.hasFailed()))
        .build();
```

## 3. 注解表

| 注解 | 作用 | 必踩坑 |
|---|---|---|
| `@SystemMessage` | 系统提示词 | 支持 `{{var}}` |
| `@UserMessage` | 用户消息模板 | 方法级 + 无注解参数 → 填 `{{it}}` |
| `@V("x")` | 模板变量 | 名字必须匹配 |
| `@MemoryId` | 会话 id | **必须配 `chatMemoryProvider`**，否则构建期抛错 |
| `@UserName` | 用户名 | 审计用 |
| `@Tool` / `@P` | 工具 / 参数 | 描述 = 给模型的 prompt |
| `@AiService`（spring） | 声明为 Spring Bean | 需 provider starter 提供模型 Bean |

## 4. 返回值形态

| 返回 | 用途 |
|---|---|
| `String` | 纯文本 |
| `T`（record/POJO/enum/List） | 结构化（**默认不强制 JSON 模式**） |
| `Result<T>` | 带 `tokenUsage()` / `sources()` / `toolExecutions()` / `finishReason()` |
| `TokenStream` | 流式，必须 `.start()` |

```java
// 建库：切分 → 向量化 → 入库
for (TextSegment seg : fixedSplit(text, 500)) store.add(emb.embed(seg).content(), seg);
```

## 7. 报错速查

| 报错 | 修法 |
|---|---|
| `cannot find symbol ChatLanguageModel` | ≥ `1.0.0-rc1` 改名 `ChatModel` |
| 依赖版本混搭报 `NoSuchMethodError` | 核心用正式号、集成件用同序号 beta 号，或用 `langchain4j-bom` |
| 引入了 `1.19.1` | 官方误发版本，升到 `1.20.0+`，**不要**改到 `1.19.2` |
| `IllegalConfigurationException: ... @MemoryId, please configure the ChatMemoryProvider` | 加 `chatMemoryProvider(...)` |
| `NoClassDefFoundError: opennlp/.../SentenceModel` | 自带切分器依赖 opennlp；补依赖或自己切分 |
| `required a bean named 'openAiChatModel' that could not be found` | 加 `langchain4j-open-ai-spring-boot-starter` |
| 启动时条件不匹配 `@ConditionalOnProperty(...api-key)` | yml 里必须存在 `api-key`（可写占位） |
| `content.metadata().get("SCORE")` 为 null | 用 `ContentMetadata.SCORE` 枚举 key |
| `metadata().toString()` 写出 `Metadata { metadata = {...} }` | 用 `metadata().toMap()` |
| `SSE 收不到 / 一次性返回` | `produces=text/event-stream`、Nginx 关 buffering |
| `maxSequentialToolsInvocations` 弃用告警 | 用 `maxToolCallingRoundTrips` |
| `toolExecutionErrorHandler` 签名不匹配 | 1.23 是 `(Throwable, ToolErrorContext) -> ToolErrorHandlerResult` |

## 8. 与 Spring AI 对照

| 能力 | LangChain4j | Spring AI |
|---|---|---|
| 声明能力 | 接口 + `@SystemMessage` | `ChatClient.prompt()` 链 |
| 中间件 | Listener / `before/afterToolExecution` | `Advisor` |
| 多会话 | `@MemoryId` + provider | `MessageChatMemoryAdvisor` + 会话 id |
| 结构化 | POJO 返回 + OutputParser | `BeanOutputConverter` / `.entity()` |
| 流式 | `TokenStream` 回调 | `Flux<String>` |
| 护栏 | 内置 Guardrail | 自写 Advisor |
| RAG 抽象 | 5 段式完整 | Advisor + VectorStore |
