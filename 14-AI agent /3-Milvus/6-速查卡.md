# Milvus 速查卡

> 一页纸能查完的东西。想深入点标题跳转：[[1-基础介绍]] · [[2-环境搭建]] · [[3-操作指南]] · [[4-AI中的用法]] · [[5-避坑与排障]]

## 1. 30 秒跑起来

```bash
# 本地开发
pip install -U "pymilvus[milvus-lite]"

# 单机生产（Docker）
curl -sfL https://raw.githubusercontent.com/milvus-io/milvus/master/scripts/standalone_embed.sh -o standalone_embed.sh
bash standalone_embed.sh start      # 19530 / 9091
```

```python
from pymilvus import MilvusClient
client = MilvusClient(uri="./demo.db")                  # Lite
# client = MilvusClient(uri="http://localhost:19530", token="root:Milvus")  # Standalone

client.create_collection("demo", dimension=4)
client.insert("demo", [{"id": 1, "vector": [0.1, 0.2, 0.3, 0.4], "text": "hello"}])
client.load_collection("demo")
print(client.search("demo", data=[[0.1, 0.2, 0.3, 0.4]], limit=1, output_fields=["text"]))
```

## 2. 常用命令表

| 目的 | 代码 |
|---|---|
| 建表（完整） | `schema = client.create_schema(auto_id=True, enable_dynamic_field=False)` + `add_field` + `client.create_collection(name, schema=schema, index_params=idx)` |
| 加字段 | `schema.add_field("text", DataType.VARCHAR, max_length=8192, enable_analyzer=True, analyzer_params={"type":"jieba"})` |
| 稀疏 + BM25 | `schema.add_field("sparse", DataType.SPARSE_FLOAT_VECTOR)` + `schema.add_function(Function(name="bm25", function_type=FunctionType.BM25, input_field_names=["text"], output_field_names=["sparse"]))` |
| 建索引 | `idx.add_index(field_name="dense", index_type="AUTOINDEX", metric_type="COSINE")` |
| 稀疏索引 | `idx.add_index(field_name="sparse", index_type="SPARSE_INVERTED_INDEX", metric_type="BM25")` |
| 标量索引 | `idx.add_index(field_name="tenant", index_type="INVERTED")` |
| 多租户 | `schema.add_field("tenant", DataType.VARCHAR, max_length=64, is_partition_key=True)` |
| 插入 | `client.insert(name, [row, ...])` → 返回 `{"insert_count", "ids"}` |
| 覆盖/局部更新 | `client.upsert(name, rows)` / `client.upsert(name, rows, partial_update=True)` |
| 条件查询 | `client.query(name, filter='tenant == "a"', output_fields=["text"])` |
| 主键读 | `client.get(name, ids=[1, 2])` |
| 向量检索 | `client.search(name, data=[vec], limit=10, output_fields=["text","source"], search_params={"ef": 64})` |
| 混合检索 | `client.hybrid_search(name, reqs, ranker=RRFRanker(k=60), limit=10, output_fields=["text"])` |
| 稀疏检索请求 | `AnnSearchRequest(data=["原始query"], anns_field="sparse", param={"metric_type":"BM25"}, limit=50)` |
| 按文档聚合 | `client.search(..., group_by_field="source")` |
| 删数据 | `client.delete(name, ids=[...])` / `client.delete(name, filter='source == "a.md"')` |
| 加载/卸载 | `client.load_collection(name)` / `client.release_collection(name)` |
| 落盘 | `client.flush(name)`（整批一次！） |
| 行数 | `client.get_collection_stats(name)` |
| 全表导出 | `client.query_iterator(name, batch_size=1000, output_fields=[...])` |
| 释放已删空间 | `client.compact(name)` |
| 平滑切换 | `client.create_alias(name, alias)` / `client.alter_alias(name, alias)` |
| 3.0 在线加字段 | `client.add_collection_field(name, field_name="x", data_type=DataType.VARCHAR, max_length=64)` |
| 3.0 快照 | `client.create_snapshot(collection_name=name, snapshot_name="s1")` |

## 3. 参数默认值 / 推荐值

| 参数 | 默认 | 推荐 |
|---|---|---|
| metric | `COSINE` | 文本 `COSINE`，图像 `L2` |
| 一致性级别 | `Bounded`（~5s） | 服务端 `Bounded` + 搜索传 `Session` |
| HNSW `M` / `efConstruction` | 8 / 64 | `16~32` / `200~400` |
| HNSW 查询 `ef` | — | `2 × limit` 起（64~256） |
| IVF `nlist` | 128 | `4·√N`，上限 65536 |
| IVF 查询 `nprobe` | — | 8~64 |
| `limit` | 10 | 最终 3~5，召回池 `limit×5~10` |
| 写入批大小 | — | 500~2000 条/批 |
| BM25 分词器 | `standard` | 中文 `jieba` |
| 稀疏检索 `drop_ratio_build` | — | **只能是 0** |

## 4. 过滤表达式速查

```text
tenant == "a"                 status != "deleted"
price >= 10 and price < 100   ts (int64) >= 1700000000000
status in ["active","trial"]  source like "docs/%"      # 只支持前缀
meta["lang"] == "zh"          ARRAY_CONTAINS(tags, "ai")
ARRAY_LENGTH(tags) > 2        TEXT_MATCH(text, "向量数据库")   # 需 analyzer
```

## 5. 报错 → 一句话修法

| 报错 | 修法 |
|---|---|
| `Schema must have a primary key field` | 传了 `schema=` 时要自己 `add_field(is_primary=True)` |
| `unknown tokenizer type: 'chinese'` | 改 `{"type": "jieba"}` |
| `only drop_ratio_build=0 is supported` | langchain：显式传 `search_params`；原生：`drop_ratio_build: 0` |
| `sparse field ... requires SPARSE_INVERTED_INDEX` | 稀疏字段索引类型写错，release→drop→recreate |
| `metric type not match` | 删表重建（metric 不能改） |
| `is in state 'released'; call load()` | `client.load_collection(name)` |
| `must specify anns_field` | `search_iterator(..., anns_field="dense")` |
| `field id not exist`（Java） | `outFields` 去掉主键 |
| 命中但 text 为空 | 补 `output_fields=["text"]` / `withOutFields(...)` |
| `Method not implemented!` | Lite 不支持该能力 → 上 Standalone |
| `unexpected character '{'` | `filter_params` 占位符不被支持，改成转义拼接 |
| `add_index() got multiple values for keyword argument 'field_name'` | langchain 的 `index_params` 里别写 `field_name` |
| `weighted merge requires 2 weights, got 4` | 改用 `reranker=Function(...)` 新写法 |

## 6. 选型速记

| 问 | 答 |
|---|---|
| FAISS 还是 Milvus？ | FAISS 是索引库；要持久化/并发/过滤/服务化就 Milvus |
| Lite 还是 Standalone？ | 本地开发 Lite；团队/生产 Standalone |
| Standalone 还是 Distributed？ | 单机内存扛得住就 Standalone |
| HNSW 还是 IVF？ | 在线首选 HNSW；内存紧用 IVF_SQ8 / DiskANN |
| RRF 还是 Weighted？ | 默认 RRF；有明确权重认知再用 Weighted |
| 多租户怎么做？ | partition key + 强制 filter；租户极少先考虑一租户一表 |
| 换 embedding 怎么办？ | 新表 + 重灌 + `alter_alias`；3.0 可在线加字段回填 |

## 7. 上线 checklist（压缩版）

- [ ] 版本：服务端 / SDK / 编排层成对，写进文档
- [ ] schema：`dim`=模型维度、`metric` 正确、`analyzer` 中文开 jieba、动态字段关闭
- [ ] 检索：`output_fields` 必传、召回池 ≥5×、混合 + rerank 有指标对比
- [ ] 权限：默认密码已改、端口不对公网、写账号只能 Insert
- [ ] 韧性：Milvus 挂了应用能降级
- [ ] 备份：volume / MinIO / etcd 一起备；重建脚本一键可跑
- [ ] 监控：p95 延迟、空召回率、行数增长、`compact` 积压
