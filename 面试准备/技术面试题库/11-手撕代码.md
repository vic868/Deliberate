## 一、Java 并发手撕（与后端面试最相关）

### 1. DCL 单例
```java
public class Singleton {
    private static volatile Singleton instance;   // volatile 必须有
    private Singleton() {}
    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();   // 1.分配 2.初始化 3.赋值
                }
            }
        }
        return instance;
    }
}
```

### 2. 生产者消费者（BlockingQueue）
```java
BlockingQueue<Integer> queue = new ArrayBlockingQueue<>(10);
// 生产者
new Thread(() -> { while (true) queue.put(1); }).start();
// 消费者
new Thread(() -> { while (true) queue.take(); }).start();
```
> 手写版用 `synchronized + wait/notify`，**注意用 while 而不是 if**（防虚假唤醒）

## 三、算法模板

### 反转链表
```java
public ListNode reverse(ListNode head) {
    ListNode prev = null;
    while (head != null) {
        ListNode next = head.next;
        head.next = prev;
        prev = head;
        head = next;
    }
    return prev;
}
```

### LRU 缓存（LinkedHashMap 版）
```java
class LRUCache extends LinkedHashMap<Integer, Integer> {
    private final int capacity;
    public LRUCache(int capacity) {
        super(capacity, 0.75f, true);   // accessOrder = true
        this.capacity = capacity;
    }
    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        return size() > capacity;
    }
}
```
> 手写版：**HashMap + 双向链表**（面试更想看你手写这个）

### 二分查找（防死循环）
```java
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;    // 防溢出
    if (a[mid] == target) return mid;
    else if (a[mid] < target) lo = mid + 1;
    else hi = mid - 1;
}
```

### 快排（分区）
```java
int partition(int[] a, int lo, int hi) {
    int pivot = a[hi], i = lo;
    for (int j = lo; j < hi; j++)
        if (a[j] < pivot) swap(a, i++, j);
    swap(a, i, hi);
    return i;
}
```

## 五、SQL 手撕

```sql
-- 第 N 高的薪水（N 为具体数字，如第 2 高）
select distinct salary from Employee order by salary desc limit 1, 1;   -- 第 2 高
-- 通用写法：limit N-1, 1  （limit offset, count）

-- 分组取每组最大值（窗口函数）
select * from (
  select *, row_number() over (partition by dept order by salary desc) rn from Emp
) t where rn = 1;

-- 连续登录 3 天（日期减 row_number）
select user_id from (
  select user_id, login_date,
         date_sub(login_date, interval row_number() over (partition by user_id order by login_date) day) grp
  from (select distinct user_id, login_date from login_log) t
) x group by user_id, grp having count(*) >= 3;
```
