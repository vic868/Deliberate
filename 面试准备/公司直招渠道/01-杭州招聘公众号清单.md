## 四、微信里怎么验证一个号是不是官方的（30 秒）

1. 微信 → 搜索框输入 `公司名 + 招聘`
2. 上方切到「**公众号**」tab（不是「文章」）
3. 点进候选号 → 右上角「…」→「**更多资料**」
4. 看「**认证主体**」：必须是该公司**全称**（如"浙江大华技术股份有限公司"）
5. 顺手点「**设为星标**」，否则推送会被淹没

> 中介号的典型特征：主体是"XX人力资源有限公司"、名字带"直招/包过/内推直通车"、文章里让你加个人微信而不是进企业 ATS。

## 五、更稳的用法：从文章反查账号

不知道账号名时的通用解法：

1. 微信搜一搜输入 `公司名 + 招聘`，这次切「**文章**」tab
2. 找到该公司发布的招聘文章（不是中介转发的）
3. 文章顶部/底部的**来源账号名**点进去 → 关注

这条路不依赖你猜对账号名，命中率最高。今天核实的这几个号基本都是这么反查出来的。

## 六、关注之后做什么（别只关注）

- [ ] 打开「**接收消息**」+ 星标，否则一周后就沉底了
- [ ] 逐个点开底部**菜单栏**：多数公司把「社会招聘」放在菜单里，文章只推校招
- [ ] 文章里常见 **内推码 / HR 邮箱 / 招聘群二维码**——这三样比投递入口更值钱
- [ ] 把公众号发布的岗位和官网 ATS 岗位**交叉核对**：公众号常先发、ATS 后同步
- [ ] 记录到 [[00-杭州企业官网招聘入口]] 的投递表里

## 七、配合使用的其他渠道

- **脉脉**：搜公司名 → 员工 → 内推（比公众号投递响应快）
- **牛企直聘 / 应届生求职网**：转载企业招聘公告，能看到"来源公众号"，用来反查账号
- **知乎/小红书**：搜「公司名 内推码」，常有员工放码
