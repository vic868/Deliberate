# 杭州企业官网招聘入口 · 直招清单

> 用途：绕过招聘平台，直接投企业自有招聘系统 / HR 邮箱。
> 配套：[[01-杭州招聘公众号清单]]（微信渠道，已核实 8 个号）
> 所有链接于 2026-10-25 实测可达（标注为「需浏览器」的是反爬，curl 打不开但浏览器正常）。

## 为什么值得单独做一份

| 对比项 | BOSS / 智联 | 企业官网直招 |
|---|---|---|
| 岗位覆盖 | 广，但热门岗几百人投 | 常有不外发的岗位，投递人数少一个量级 |
| 简历去向 | 平台内推给 HR，可能被算法过滤 | 直接进企业 ATS（人才库），可被搜到 |
| 响应速度 | 取决于 HR 是否活跃 | 大厂 ATS 有 SLA，通常 3-5 个工作日 |
| 可追踪性 | 弱 | 可查投递状态、可内推编号 |

结论：**官网直投 + 内推双轨**，平台只做补充。

## 三、通用方法：怎么给任何一家公司找到官网招聘入口

这部分可以复用到你以后遇到的任何公司，30 秒内出结果。

### 1. 先试 URL 套路（最快，命中率约 60%）

```
主域 + 路径：  /join    /joinus   /careers   /career   /zhaopin
              /recruit /talent   /hr        /about/join
子域：         job.X.com   talent.X.com   hr.X.com   careers.X.com
```

实测命中例：
- 恒生 → `job.hundsun.com`　同花顺 → `job.10jqka.com.cn`
- 大华 → `job.dahuatech.com`　宇视 → `talent.uniview.com`
- 新华三 → `h3c.com/cn/About_H3C/Job/`　中控 → `supcon.com/join`

### 2. 搜索引擎运算符

```
site:hundsun.com 招聘
site:hundsun.com 加入我们
"公司名" 社会招聘 官网
"公司名" 内推
```

### 3. 认第三方 ATS 托管页（看到就知道是这家在用）

| 托管商 | 域名特征 | 说明 |
|---|---|---|
| **Moka** | `app.mokahr.com/social-recruitment/<公司英文>/<id>` | 杭州公司用得最多（袋鼠云、税友、涂鸦早期都是） |
| **北森** | `*.hotjob.cn` / `*.zhiye.com` | 大厂/上市公司常见 |
| **牛客** | `nowcoder.com` | 校招为主 |
| **飞书招聘** | `*.jobs.feishu.cn` | 新经济公司 |
| **Workday** | `*.wd3.myworkdayjobs.com` | 外企 |

### 4. 微信公众号（重要，很多岗位只在这里发）

微信搜「公司名 + 招聘」，尤其：
- **安恒信息**：常发「总裁直聘」岗位，直接对高管
- 海康/大华/宇视：校招社招公告 + 内推码
- 同盾/邦盛：风控专场

### 5. 校招 vs 社招要分清

社招入口通常在页面有「**社会招聘 / Social**」tab，校招页面投社招岗会被系统丢掉。
例：宇视 `talent.uniview.com/wt/uniview/web/index/social`。

## 四、每次投递的固定动作（照着做，别凭感觉）

- [ ] 官网直投 **+** 找内推双轨并行（内推能跳过初筛，优先级高于直投）
- [ ] 简历统一命名：`张勇-Java技术经理-14年-杭州.pdf`
- [ ] 记录到下面的表里（公司 / 岗位 / 入口 / 投递日 / 状态 / 联系人）
- [ ] 投完 24 小时内，去脉脉搜该公司 HR 或技术负责人，加好友时一句话说明「投了 XX 岗，附简历要点」
- [ ] 每周固定两次批量投（周一、周四），其余时间只做内推和跟进
- [ ] 7 个工作日无回应 → 换渠道再投一次（官网 → 内推 → 猎头）
