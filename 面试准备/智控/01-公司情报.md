# 🏢 智控网络 公司情报

> [!abstract] 一句话定位（面试能脱稿讲出来）
> 智控（ZKONG）是**基于 IoT 技术的电子价签（ESL）全球化领跑者**——
> 2006 年起家于无线通信，2017 年全球首发 SaaS 架构 ESL 方案，
> 现在做「**ESL 电子价签 + LCD 商显屏 + 无线基站 + SaaS 云平台**」的智慧零售全链路方案，
> 总部杭州，业务覆盖 60+ 国家，合作品牌 3000+，部署门店 20 万+。

## 2. 产品线（面试官可能问"你了解我们做什么吗"）

### ESL 电子价签（EPD 电子纸，7 大系列）
| 系列 | 定位 | 关键特征 |
|---|---|---|
| **ARROW** | 长条拼接 | 多 SKU、密集货架、横向拼接、亚克力面板 |
| **SHIELD** | 坚固防护 | 亚克力面板、高客流量、露天/低温场景 |
| **VALLEY** | 无面板 | 低反光、外观简洁、自然易读（尺寸最全，1.5"~11.6"） |
| **BLADE** | 超薄 | 极简边框、信息密集、多页切换 |
| **BLADE + PTL** | 亮灯拣选 | 无线拣货灯、自动仓储管理、快速定位 |
| **QUANTUM** | 超窄边框 | 高屏占比、高密度货架 |
| **FASHION** | 服装零售 | 易悬挂、小尺寸、高传输效率 |
| **ESSENCE** | 全彩大尺寸 | 全彩电子纸、智慧办公、园区管理、配件定制 |

### 其他
- **LCD 商显屏**：SPARKLE（10.1"~15.6"，可多屏集成）／LEGENDARY（23.1"~65"，大型购物中心高端场景）
- **无线云基站 ZAP 系列**（ZAP-C / DX / DL / U）：
  - **单基站可管 15000+ 片价签**，多 AP 负载均衡
  - 室内覆盖 **700㎡**，无障碍直径 20m
  - 支持千兆以太网 / WiFi / CAT1；SSL/TLS 加密
  - 支持 BLE、Sub-1GHz、Wi-Fi 等制式定制
- **SaaS 云平台**：ESL + LCD + 全硬件统一管理；**秒级同步更新，15 分钟实现全店切换**；开放 API
- **AoA 定位**（新发布）：货品定位、商品导航、员工管理、门店防盗；大型连锁超市实测准确率 **97%**
- **PTL 亮灯拣选**：仓储物流拣货，降低错误率

### 价签产品优势参数（技术面试的金矿）
> 四色显示（红/黄/黑/白）· 宽视角 ~180° · 高 DPI ≥140 · 蓝牙 5.4 / NFC · 工作温度 -25~40°C
> 传输速率 **1.3 Mb/s** · 待机电流 **2.9 uA** · 秒级信息切换 · 自主翻页 · 适应低温 ≥-25℃

### 部署模式（宣传册专门对比）
**云部署（SaaS）**：初始成本低、托管维护、快速部署、高扩展性、远程访问、内置冗余
**本地部署**：初始与维护成本高、需内部独立维护、安全性更高、受物理资源限制、依赖当地基础设施

### 行业覆盖
零售商超 · 时尚美妆 · 消费电子 · 仓储物流 · 智慧办公 · 药店医疗

## 3. ⚡ 从产品参数反推的「后端技术命题」（最高价值）

> [!important] 这一节是本笔记的核心
> 面试官大概率会让你做系统设计。**把智控的业务参数翻译成技术挑战**，
> 你就从"背八股的候选人"变成"懂我们业务的人"。

| # | 业务参数 | 反推的技术命题 | 关键词 |
|---|---|---|---|
| 1 | 单基站 15000+ 价签、20 万门店 | 海量长连接设备接入网关 | Netty、MQTT、无状态网关、会话路由、重连风暴 |
| 2 | 秒级同步 / 15 分钟全店切换 | 批量指令下发与一致性 | 任务编排、削峰、回执聚合、幂等、补偿 |
| 3 | **待机电流 2.9uA（电池供电）** | 硬件约束反推后端设计 | 报文精简、差分更新、合并下发、心跳可配 |
| 4 | 3000+ 品牌共用 SaaS | 多租户隔离 | tenant_id 分片、越权防护、配额限流 |
| 5 | 60+ 国家、欧洲/日本/香港 | 全球化架构 | 多区域部署、就近接入、**GDPR 数据驻留**、时区多语言 |
| 6 | 云部署 + 本地化部署双形态 | 一套代码两种交付 | 配置化、依赖抽象、离线 License、升级包 |
| 7 | 门店弱网/离线 | 最终一致性 | 待下发队列、版本号增量、TTL 丢弃、对账兜底 |
| 8 | 与客户 POS/ERP 对接 | 开放 API 平台 | 签名鉴权、幂等键、限流、异步回调、对账 |
| 9 | AoA 定位（97% 准确率） | 高频定位数据处理 | MQ 削峰、时序库/ClickHouse、降采样 |
| 10 | 促销期海量改价峰值 | 流量治理 | 排队、优先级、资源隔离、压测、降级 |
