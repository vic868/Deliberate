## 3. 高风险问题与应对（十年经验专属）

| 问题                  | 应对思路                                                   |
| ------------------- | ------------------------------------------------------ |
| 「你经验这么多，为什么来做开发岗？」  | 认同业务方向（IoT 出海 + SaaS 体量）+ 想回技术一线做深。**别贬低自己，也别显得只是来过渡** |
| 「我们这个岗位预算可能达不到你的预期」 | 「我想先了解岗位定级和完整薪酬结构」→ 不现场松口                              |
| 「你带过团队吗？怎么带的？」      | 具体事实：团队规模、分工方式、交付结果、怎么处理冲突/延期                          |
| 「为什么离开上一家？」         | 客观、向前看，**不抱怨前公司**                                      |
| 「能接受加班吗？」           | 就事论事：需要时能顶，长期靠流程和效率解决。别过度承诺                            |
| 「你最大的缺点？」           | 真实但可控 + 你正在怎么改进                                        |
| 「职业规划？」             | 3 年：技术深度 + 架构能力；与智控的 IoT/SaaS 方向绑定                     |
| 「你对我们还有什么想了解的？」     | 用下面第 4 节的清单，**别答"没有了"**                                |

## 4. 反问清单（体现"负责人"视角）

### 问业务/技术（优先，显得懂行）
1. 目前 ESL 云平台的**设备接入层**是什么量级？自研网关还是 MQTT 中间件？
2. 改价指令从云端下发到价签刷新，**端到端延迟**目前什么水平？最大瓶颈在哪？
3. 3000+ 品牌的多租户，数据隔离目前是哪种方案？
4. 出海多区域部署，欧洲的数据合规怎么处理？
5. 云平台的技术栈大概是？（Java 版本 / Spring Cloud / MQ / 存储）

### 问岗位（关键，直接决定你去不去）
6. 这个岗位属于**中级还是高级**？团队多少人、怎么分工？
7. 我 10+ 年经验，团队期待我承担**纯开发**还是能参与架构 / 带人？
8. 未来 6-12 个月，这个岗位最重要的交付目标是什么？
9. 研发流程（需求→上线）、发布频率、有没有线上值班？

### 谈薪铺垫
10. 薪资结构和调薪机制？（**先确认定级再谈数字**）

> [!tip] 挑 3-4 个问就够了，别把面试官问烦。

## 5. 面试当天的表达技巧

- 先说结论，再说理由（**STAR / PREP**）
- 不会的题：**坦白 + 讲你的思路**，比硬编好得多
- 被追问到细节：诚实说"这块我当时没深入，我的理解是…"
- 主动抛钩子：讲项目时留一两个"深挖点"，引导面试官往你熟的方向问
- 语速放慢，**不要抢答**
