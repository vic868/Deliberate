
`MessagesPlaceholder` 是实现记忆的**核心机制**：
- 它像一个**插槽**，运行时会被实际的消息列表替换

- System prompt 固定角色，历史消息动态注入

```python

```

```
输入 dict → Prompt 模板格式化 → LLM 调用 → 字符串解析
```

### 第二段：手动管理历史 ✅ 正确示例（L32-37）
```python
history = ChatMessageHistory()
history.add_user_message("你好，我是云帆")
response = chain.invoke({"messages": history.messages})
history.add_ai_message(response)   # ← 关键：手动把 AI 回复回写到 history
response = chain.invoke({"messages": history.messages})
```

**流程图示：**
```
第1轮: history = [User("你好，我是云帆")]
        → LLM 回复 → AI("你好云帆...")
        → 手动回写 → history = [User, AI]

第2轮: history = [User("你好，我是云帆"), AI("你好云帆...")]
        → LLM 看到完整历史 → 能记住"云帆"这个名字
```

**这就是 `ChatMessageHistory` 的作用**：一个内存中的消息列表容器，提供了 `add_user_message()` / `add_ai_message()` 方便操作。
