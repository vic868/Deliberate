## 📖 逐段代码解析

### 导入部分
```python
from langchain_core.runnables import RunnableParallel, RunnablePassthrough
```
从 LangChain 核心模块导入两个关键的 Runnable 组件，它们是构建 LangChain 链（Chain）的基础积木。

---

### 示例 1：原样透传 + 并行修改

```python
runnable = RunnableParallel(
    passed=RunnablePassthrough(),
    modified=lambda x: x["num"] + 1,
)

print(runnable.invoke({"num": 1}))
```

**核心概念：**

| 组件 | 作用 |
|---|---|
| `RunnableParallel(...)` | 并行执行多个 Runnable，把结果按 key 组装成**一个字典**返回 |
| `RunnablePassthrough()` | **什么都不做**，输入什么就原样输出什么（恒等映射） |

**执行流程：**

```
输入: {"num": 1}
        ├──→ RunnablePassthrough()  ──→ {"num": 1}     (原样透传)
        └──→ lambda x: x["num"]+1   ──→ 2             (取 num 加 1)
                    ↓
输出: {"passed": {"num": 1}, "modified": 2}
```

**实际应用场景：**在链中需要同时保留原始输入和处理后的结果时非常有用。

---

### 示例 2：透传同时追加字段（`assign`）

```python
runnable = RunnableParallel(
    passwd=RunnablePassthrough().assign(quer=lambda x: x["num"] + 2),
    modified=lambda x: x["num"] + 1,
)

print(runnable.invoke({"num": 1}))
```

**新增概念 — `.assign()` 方法：**

`RunnablePassthrough().assign(**kwargs)` 会创建一个新 Runnable，它会：
1. 先**原样透传**输入
2. 再用 `kwargs` 中的函数计算新字段
3. 把新字段**追加**到原字典中一起输出

**执行流程：**

```
输入: {"num": 1}
        ├──→ Passthrough().assign(quer=num+2)
        │         ├─ 透传原字段: {"num": 1}
        │         └─ 追加 quer:  1+2 = 3
        │         → 合并: {"num": 1, "quer": 3}
        │
        └──→ lambda x: x["num"]+1 ──→ 2
        
输出: {"passwd": {"num": 1, "quer": 3}, "modified": 2}
```

**实际应用场景：**这是 LangChain 中最常见的模式之一，比如在 RAG 链中：
```python
chain = {
    "context": retriever | format_docs,
    "question": RunnablePassthrough()
} | prompt | llm
```
用 `RunnablePassthrough()` 把用户的原始问题保留下来，同时并行跑检索器拿到上下文。

## 总结对比

| 写法 | 行为 |
|---|---|
| `RunnablePassthrough()` | 纯透传，输出 = 输入 |
| `RunnablePassthrough().assign(k=fn)` | 透传 + 追加字段 |
| `RunnableParallel(k1=r1, k2=r2)` | 并行执行多个 Runnable，按键名聚合结果 |
