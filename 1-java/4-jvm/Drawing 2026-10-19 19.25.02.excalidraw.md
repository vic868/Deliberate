JDK 21（LTS）：引入了性能更强的分代 ZGC（Generational ZGC），但此时默认是不分代的。如果想开启分代，需要手动组合参数：-XX:+UseZGC -XX:+ZGenerational。 ^YQ90A4Ps

JDK 23：默认开启分代 ZGC。在这个版本中，你只需要输入 -XX:+UseZGC，JVM 就会自动采用更高效的分代模式。 ^KX69JYu3

JDK 24 及以后：彻底移除了老旧的不分代 ZGC 代码，分代 ZGC 成为了 ZGC 的唯一模式。 ^Ajk8LcEY

G1 全称 Garbage First（垃圾优先）。传统 GC 是按代来回收；G1 换了个思路——按 region 来回收，哪个 region 垃圾最多就优先回收哪个。所以它不关心对象是年轻还是老，只关心哪里垃圾多。 ^pb78IOwR

region ^dtgwlb48

G1 把堆切成很多等大的 region，默认每个 1MB ~ 32MB
2 的幂，约 堆大小 / 2048，可用 -XX:G1HeapRegionSize 调整 ^eGbbFgJu

每个 region 在任意时刻只有一个角色：Eden、Survivor、Old 或空闲——但角色不是固定的，GC 回收完一个 region，它就变成空闲，下次可以重新分配 ^S83qArnd

G1 用了两个机制
Card Table 和 Remembered Set ^SCzY9U46

young GC 要回收年轻代，但老年代的对象可能引用了年轻代的对象——怎么知道哪些老年代对象有引用？G1 用了两个机制：Card Table 和 Remembered Set。 ^JrhrwxEK
