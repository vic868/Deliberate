# PMP 考试高频场景整理

## 1. 干系人场景（Stakeholder）
**常见考法**：项目中期新增干系人 / 干系人提出新需求 / 干系人抵制变更 / 干系人支持度下降。

**答题套路**：
- 第一步永远是**先识别 + 记录**：更新干系人登记册（Stakeholder Register），不是直接答应或忽略。
- 用**权力/利益矩阵（Power/Interest Grid）**分类，先做**权力高+利益高**的干系人。
- 按沟通需求分析更新**干系人参与计划**，用合适的沟通方式提升其参与度。
- 干系人对项目不了解 → 提供**项目状态报告/项目章程**；抵制 → 更新参与策略、一对一会谈。
- 干系人提出新需求 → **提交变更请求**走变更控制流程，不是直接做。

> 黄金准则：先记录进登记册 → 评估影响 → 更新参与计划 → 沟通。

## 2. 冲突管理场景（Conflict Management）
**常见考法**：团队成员之间、团队与客户之间发生冲突。

**答题套路**：
- 冲突是**不可避免**的，不是坏事，正常管理即可。
- 五大人际冲突解决方法（Thomas-Kilmann），记住优先级：
  1. **合作/解决问题（Collaborate/Problem Solve）** ← 最佳答案，直面问题
  2. **妥协（Compromise）** — 双方各让一步
  3. **缓和/包容（Smooth/Accommodate）** — 强调一致、淡化分歧
  4. **强迫/强制（Force/Direct）** — 单方压倒
  5. **撤退/回避（Withdraw/Avoid）** — 最差，不作为
- 考"冲突阶段"：团队发展五阶段（组建→风暴→规范→执行→解散），冲突多发生在**风暴期（Storming）**。
- 项目经理要先**亲自介入调解**，解决不了再升级。

> 黄金准则：能用"合作解决问题"绝不选别的；先内部解决，再升级。

## 3. 项目经理权利与上报场景（Escalation）
**常见考法**：PM 无法决策 / 资源或资金不足 / 超出 PM 权限 / 干系人之间冲突无法调和。

**答题套路**：
- PM 能解决的，**绝不上报**；确实超出职权范围才升级。
- 上报对象是**发起人（Sponsor）**，不是 HR 或客户。
- 涉及变更、资金增加 → 走**变更控制流程** + 可能需要**管理储备（Management Reserve）**。
- 资源不足且协商失败 → 先**谈判**，再报**发起人**协调或申请预算。
- 风险导致 → 走**风险应对** + 上报发起人。

> 黄金准则：先穷尽 PM 权限内手段 → 再找发起人 → 涉及变更先走变更控制。

## 4. 获取资源场景（Acquire Resources）
**常见考法**：人手不够 / 团队缺技能 / 设备被其他项目占用。

**答题套路**：
- 缺人手 → 先**协商**：与职能经理、其他项目经理、供应商谈判，不是直接招人。
- 缺技能 → 先**培训现有团队**，再考虑**招募/外包**。
- 资源被占用 → 查看**资源日历**，协调共享资源，必要时**资源平衡（Leveling）/资源平滑（Smoothing）**。
- 谈判前先看**资源管理计划**和**人员配备管理计划**。
- 资源不足导致无法按计划 → 提**变更请求**调整进度/范围。

> 黄金准则：先看计划 → 内部协调/培训 → 谈判 → 变更请求，最后才招人。

## 5. 索赔管理场景（Claims Management）
**常见考法**：合同纠纷 / 供应商索赔 / 业主索赔 / 工期延误责任。

**答题套路**：
- 索赔分**变更索赔**（甲方变更引起）和**违约索赔**（乙方违约引起）。
- 第一步：**查阅合同条款**，确认索赔依据和时效。
- 双方有争议 → 先协商，不行走**替代争议解决（ADR）**，再**仲裁（Arbitration）**，最后**诉讼**。
- 管理索赔要用**索赔数据**记录过程，重大索赔报**法律/法务**。
- PM 要在**合同收尾**前处理完所有索赔并结清。
- 关键：索赔不等于变更，变更走变更流程，索赔走合同纠纷流程。

> 黄金准则：先查合同 → 协商 → ADR/仲裁/诉讼 → 合同收尾前结清。

## 6. 虚拟团队场景（Virtual Teams）
**常见考法**：团队分散各地 / 跨时区 / 远程协作困难。

**答题套路**：
- 建立**沟通管理计划**，明确沟通工具、频率、时区约定。
- 制定**团队章程（Team Charter）**/基本规则：会议时间、响应时限、决策方式。
- 通过**虚拟团队建设活动**增强信任与凝聚力（定期视频会、破冰）。
- 注意**跨文化差异**，用文化意识管理沟通。
- 虚拟团队的绩效问题 → 先检查**沟通是否顺畅 + 是否有明确目标**，再考虑调整。

> 黄金准则：先建规则和沟通计划 → 用工具 + 团队建设 → 关注文化差异。
