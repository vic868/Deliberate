# DrawIO 嵌入示例

下面用 `![[drawio示例.drawio]]` 语法把刚才建的 draw.io 图嵌进笔记（阅读视图下渲染成图，点击图可以回到编辑器修改）：

![[juc.drawio]]

## 用法备忘

- 新建：命令面板 `Cmd+P` → `Drawio: Create new diagram`，或左侧栏底部「Create new drawio diagram」图标
- 编辑：直接点开任意 `.drawio` 文件（内嵌编辑器，完全离线）
- 嵌入：`![[文件名.drawio]]`
- 导出：命令面板 → `Drawio: Export diagram as SVG / PNG`
