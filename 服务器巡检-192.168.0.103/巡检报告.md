### 异常容器：clash（crash-loop）

- 重启次数：**3225 次**，ExitCode 255，非 OOM。
- 日志报错：`FTL [Config] parse config failed error=external-ui: /root/.config/clash/ui not exist`
- **根因：挂载路径配错**。宿主机 `/opt/docker/clash/ui` 被挂到了容器内 `/opt/docker/clash/ui`（原样路径），而配置要求 UI 目录在容器内 `/root/.config/clash/ui`。

```text
# docker inspect clash 的两个挂载
/opt/docker/clash/ui     -> /opt/docker/clash/ui      # ← 目标路径错了
/opt/docker/clash/config -> /root/.config/clash       # 配置目录本身是对的
```

> [!note] 修复思路
> 把挂载目标改为 `/opt/docker/clash/ui:/root/.config/clash/ui`，或注释掉 config.yaml 里的 `external-ui` 行。详见 [[修复清单]]。

### 3000 端口站点的问题

nginx 只启用了 `urban-renewal` 一个站点，其中 `/api/` 反代到 `localhost:8080`：

```text
listen 3000;
root /var/www/urban-renewal;
location /api/ { proxy_pass http://localhost:8080/api/; }
```

但 **8080 上没有任何进程监听** → `GET /api/` 返回 **502**。该站点还通过 frp 发布到了公网（见下），访客用接口功能会直接失败。

## 四、公网链路（frp）

配置文件 `/opt/frp_0.64.0_linux_amd64/frpc.toml`：

```toml
serverAddr = "124.221.51.4"
serverPort = 6770

[[proxies]]
name = "城市更新服务平台"
type = "http"
localIP = "127.0.0.1"
localPort = 3000
subdomain = "demos"
```

即：**公网用户 → 124.221.51.4（demos 子域名）→ 本机 3000 端口的 urban-renewal 站点**。因为 8080 后端未启动，公网访客目前只能看到静态页面。

## 五、80 端口的归属

宿主机 80 端口由 **`risk-admin-frontend` 容器内的 nginx** 直接占用（host 网络模式，进程 cgroup 在 docker scope 下），返回「风控管理系统」页面；系统级 nginx（systemd）只占 3000。

> [!caution] 注意
> 系统 nginx 以后新增站点**不要再用 80 端口**，会被前端容器抢占冲突。
