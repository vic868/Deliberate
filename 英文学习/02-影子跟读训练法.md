# 影子跟读（Shadowing）训练法 + 材料库

> Shadowing 是口译员的训练法，也是**性价比最高的口语训练**：同时练听力、发音、语流、语感。
> 你不需要理解每个词，你需要的是让嘴巴和耳朵**同步**。

## 一、正确姿势（90% 的人做错了）

### 三个层次，逐级升级

| 层次 | 做法 | 难度 | 何时用 |
| --- | --- | --- | --- |
| L1 跟读 | 听一句 → 暂停 → 模仿一句 | ★ | 第 1 周 |
| L2 影子 | 音频不停，落后 1–2 秒同步跟读 | ★★★ | 第 2 周起主练 |
| L3 同步 | 几乎与音频同时说，模仿语调语速 | ★★★★★ | 第 4 周后 |

### 标准 10 分钟流程

1. **盲听 2 遍**：只听，不看文本，抓大意
2. **看文本 1 遍**：只查 ≤3 个关键词，标注连读处
3. **L1 跟读 3 遍**：逐句暂停模仿，重点模仿**语调**不是单词
4. **L2 影子 5 遍**：不暂停，跟不上就"哼"过去，别停
5. **脱文本影子 2 遍**：关掉字幕
6. **录音 1 遍**：回听，只关注"哪里卡了"

> **关键纪律：跟不上也要继续说，绝不停下来。** 停下来就破坏了语流训练。

### 要模仿什么（按重要性排序）

1. **句子重音**：英文是"重音节拍语言"，实词重读、虚词弱读
2. **语调走向**：陈述句降调、一般疑问句升调
3. **连读与弱读**：`kind of` → `kinda`，`want to` → `wanna`，`at the` → `atta`
4. **停顿位置**：在语义块之间停，不是在每个词后停
5. **音色**：最后才管这个，几乎不重要

## 三、精听补充法（治"听不出来"）

影子跟读治语流，**精听治辨音**。每周做 2 次，每次 15 分钟：

1. 选 30 秒音频，**盲听 3 遍**，写下你听到的（哪怕乱码）
2. 对照原文，**圈出没听出来的部分**
3. 分析原因：
   - 生词？→ 记进词汇本
   - 连读？→ 标注音变，跟读 10 遍
   - 语速？→ 0.75x 慢放再听
4. 第二天再盲听同一段，直到 100% 听懂

> **同一个材料反复听 5 遍，胜过 5 个新材料各听 1 遍。**

## 四、发音纠音清单（中国程序员高频错音）

| 易错点 | 常见错误 | 纠正 |
| --- | --- | --- |
| /θ/ /ð/ | think → sink, this → dis | 舌尖轻触上齿 |
| /v/ /w/ | very → wery | v 上齿咬下唇 |
| /l/ 结尾 | tool → too | 舌尖顶上齿龈 |
| /æ/ /e/ | bad → bed | 嘴张大 |
| 词尾辅音 | and → an, code → co | **词尾音必须发出来** |
| 重音位置 | deVELopment → DEvelopment | 查词典标重音 |
| -ed 结尾 | worked → work-ed | 分清 /t/ /d/ /ɪd/ |

**自查方法**：用手机语音输入法说英文，看它识别成什么。识别错 = 发音有问题。
