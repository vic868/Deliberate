# 技术表达与词汇（说你每天都在做的事）

> 你已经懂技术，缺的只是**英文说法**。这张表按"你每天都会用到"排序。

---

## 一、架构与系统（Architecture）

| 中文 | 英文 | 例句 |
| --- | --- | --- |
| 微服务 | microservices | We split the monolith into microservices. |
| 单体应用 | monolith | The monolith became hard to deploy. |
| 分布式系统 | distributed system | It's a distributed system with 30 services. |
| 高可用 | high availability | We need high availability across two regions. |
| 可扩展性 | scalability | The main concern is scalability. |
| 容错 | fault tolerance | We added fault tolerance at the service level. |
| 负载均衡 | load balancing | Requests go through a load balancer. |
| 限流 | rate limiting | We put rate limiting on the public API. |
| 熔断 | circuit breaker | The circuit breaker opens after 5 failures. |
| 降级 | graceful degradation | We degrade to a read-only mode. |
| 幂等 | idempotent | The endpoint needs to be idempotent. |
| 一致性 | consistency | We chose eventual consistency. |
| 分区容忍 | partition tolerance | CAP is about consistency, availability, and partition tolerance. |
| 单点故障 | single point of failure | The database was a single point of failure. |

| 中文 | 英文 | 例句 |

## 七、数字化表达（面试必用）

> **没有数字的回答 = 没有说服力的回答。**

| 场景 | 句式 |
| --- | --- |
| 规模 | It handles about **50,000 QPS** at peak. |
| 提升 | We cut p99 latency **from 800ms to 120ms** — a **6x improvement**. |
| 成本 | We reduced infrastructure cost **by 40%**, about **$20K a month**. |
| 团队 | I led a team of **six engineers**. |
| 时间 | We shipped the MVP in **six weeks**. |
| 可用性 | We went from **99.9% to 99.99%** availability. |
| 数据量 | The table grew to **2 billion rows**. |

**练习**：给你做过的每个项目写 3 个带数字的句子，背下来。

## 九、每日一词训练法

1. 从今天的工作里挑 **3 个**你做过的技术动作（如"加了缓存击穿保护"）
2. 查出英文表达，写进本笔记
3. 造一个**你自己项目**的句子，大声说 10 遍
4. 第二天复习，用它讲 30 秒

> **不要背技术词典。背"你今天做的事"。**
