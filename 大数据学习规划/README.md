## 为什么大数据要学（和 AI 的关系）

> [!tip] 复合定位的价值
> 1. **RAG/Agent 需要数据底座**：知识库、日志、特征都来自数据平台
> 2. **AI 落地要处理实时数据**：实时特征、实时推理、实时监控
> 3. 面试 AI 负责人时，能讲"**数据链路 + AI 应用**"是巨大加分项
> 4. 你已有的 Java + 大数据经验，让 AI 应用开发更有"系统观"
