1. Advisors 切面机制 (Client & Advisor Layer)
类似 Spring AOP 的 Around 通知拦截，在请求发送前后自动挂载会话记忆（ChatMemory）与 RAG 检索知识。
2. ChatModel 统一抽象 (Model API Layer)
统一的客户端规范，抹平 OpenAI、DeepSeek、Ollama 等底层厂商协议差异，支持零成本平滑切换。
3. MCP 上下文协议 (Tools & Protocols)
Spring AI 2.0+ 原生引入的标准上下文协议，支持以 Client 或 Server 模式调用外部工具系统[cite: 2]。
4. Modular RAG 模块化检索流水线
ETL 流水线（Reader/Transformer/Writer）结合检索前意图重写与检索后上下文压缩重排[cite: 2]。
