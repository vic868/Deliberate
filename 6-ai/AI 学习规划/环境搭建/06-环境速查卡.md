# ⚡ 环境速查卡

> [!tip] 打印出来贴在显示器边上
> 一页纸覆盖日常 90% 的环境操作。

## 1. 路径速记

| 对象 | 路径 |
| --- | --- |
| Conda 根目录 | `/opt/anaconda3` |
| conda 配置文件 | `~/.condarc` |
| pip 配置文件 | `~/.pip/pip.conf` |
| 环境目录 | `~/.conda/envs/<env>` |
| 解释器 | `~/.conda/envs/<env>/bin/python` |
| shell 脚本 | `/opt/anaconda3/etc/profile.d/conda.sh` |
| PyCharm 项目 | `~/PycharmProjects/PythonProject2` |
| 配置目录 | `~/Library/Application Support/obsidian/obsidian.json` |

## 2. Conda 必备命令

```bash
# 初始化
conda init zsh && exec zsh

# 镜像配置
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge
conda config --set solver libmamba
conda config --set channel_priority strict
conda config --set show_channel_urls yes
conda config --show

# 环境
conda create -n ai-core python=3.11 -y
conda activate ai-core
conda deactivate
conda env list
conda env remove -n ai-core -y
conda create -n ai-core --clone ai-api

# 包
conda install -n ai-core numpy -y
conda list -n ai-core
conda remove -n ai-core numpy
python -m pip install openai        # ★ 用 python -m pip
python -m pip check

# 导出
conda env export -n ai-core --from-history > environment.yml
conda env create -f environment.yml

# 清理
conda clean -a -y
python -m pip cache purge
```

## 3. PyCharm 必备路径

| 操作 | 路径 |
| --- | --- |
| 打开设置 | `⌘ ,` |
| 解释器 | `Settings → Project → Python Interpreter` |
| 运行配置 | `Run → Edit Configurations…` |
| 内置终端 | `View → Tool Windows → Terminal` |
| Python Console | `View → Tool Windows → Python Console` |
| 清缓存重启 | `File → Invalidate Caches / Restart` |
| 内存设置 | `Help → Change Memory Settings` |

## 4. 三条诊断命令

```bash
which python && python -V && python -c "import sys; print(sys.executable)"
conda env list
python -m pip list | head -30
```

## 6. 新建项目标准动作（5 步）

```bash
conda create -n ai-xxx python=3.11 -y
conda activate ai-xxx
python -m pip install -U pip && python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
# 装依赖（见 [[04-AI 依赖清单与镜像源]]）
conda env export -n ai-xxx --from-history > environment.yml
```

然后 PyCharm：`Add Interpreter → Conda → Existing → /Users/vic/.conda/envs/ai-xxx/bin/python`

## 7. 应急对照

| 现象 | 一行解决 |
| --- | --- |
| 装包巨慢 | `conda config --set solver libmamba` + 配镜像 |
| 命令找不到 | `conda init zsh && exec zsh` |
| 脚本里用不了 activate | `conda run -n env python x.py` |
| 环境找不到了 | `conda env list` 查真实路径 |
| IDE 报缺包 | 重新 Add Interpreter 选对环境 |
| 磁盘满 | `conda clean -a -y && python -m pip cache purge` |
