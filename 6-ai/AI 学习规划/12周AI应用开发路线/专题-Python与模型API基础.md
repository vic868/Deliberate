# Python 与模型 API 基础

## 学习目标

能用 Python 写一个边界清楚的命令行助手，并能解释 API 调用中的失败模式。重点是应用开发需要的基础，不要求在两周内学习模型训练或复杂数值计算。

## Python 最小范围

- 基本类型、条件、循环、函数、模块和类。
- 异常处理：区分输入错误、网络错误、服务端错误和解析错误；避免空泛地捕获所有异常。
- 虚拟环境与依赖锁定；了解配置通过环境变量注入。
- JSON、文件、命令行参数和类型标注。
- 编写小函数并验证边界输入。

## API 调用流程

```text
读取输入与配置
  → 校验输入和密钥
  → 构造请求（模型、消息、参数）
  → 设置连接/读取超时
  → 发送请求
  → 分类处理 HTTP 与网络错误
  → 解析 JSON 或流式事件
  → 校验业务结果并输出
```

## 可靠性要点

- 超时必须有上限；连接超时和整体读取超时可以分别设置。
- 重试只用于适合重试的暂时性失败，采用有限次数和退避；非幂等写请求需考虑幂等键。
- 对 4xx、限流、5xx、网络错误和响应格式错误给出不同诊断。
- 流式响应按事件逐段读取，处理结束标志、连接中断和不完整输出。
- JSON 模式或结构化输出也要做本地 Schema/字段校验；不能仅凭“模型承诺 JSON”。
- 日志记录请求 ID、耗时、状态和错误类别；隐藏密钥，审慎处理用户原文。

## 验收清单

- [ ] 能从标准输入或命令行参数读问题。
- [ ] 支持一次普通响应和一次流式响应。
- [ ] 能将结构化结果解析到类型化对象，并处理非法字段。
- [ ] 超时、无效密钥、限流和服务错误会给出可理解提示。
- [ ] 配置和密钥不硬编码；README 说明运行方式。
