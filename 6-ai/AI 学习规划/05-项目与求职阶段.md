# 阶段四 项目与求职（1.5 周）

> [!quote] 唯一目标
> 把能力变成 **offer**。一切以"拿到面试 → 拿到 offer"为准。

## 求职冲刺流程

```mermaid
flowchart LR
    A[打磨项目<br>2 个代表作] --> B[部署上线<br>线上演示]
    B --> C[重写简历<br>量化指标]
    C --> D[刷面试题<br>系统设计]
    D --> E[每天投递 10+<br>渠道：内推>BOSS>猎聘]
    E --> F[🎉 Offer]
```

## Day 1-2 · 项目打磨

> [!example] 用 [[实战项目]] 里的 RAG + Agent 两个代表作

- [ ] README：背景 + 架构图 + 亮点 + 量化指标 + 演示地址
- [ ] 部署到免费云，确保线上可演示
- [ ] 录 2 分钟演示视频

## Day 3 · 简历与作品集

> [!tip] 简历对标"负责人"写法
> - 标题：资深 Java 工程师 · AI 应用开发方向
> - 项目量化：`效果用数字`（准确率 85%→93%、成本降 60%）
> - 关键词：Spring AI、RAG、Agent、MCP、向量库
> - 哪怕带过 1-2 人也写"团队管理经验"

- [ ] 重写简历 + 1 分钟/3 分钟自我介绍
- [ ] 2 篇技术博客（掘金/CSDN）
- [ ] GitHub 主页整理 + 置顶项目

## Day 4-7 · 面试冲刺 + 投递

- [ ] 刷 [[面试准备]] 高频题
- [ ] 每天 1 道系统设计题（白板讲架构）
- [ ] 模拟面试 2 次
- [ ] 每天投递 10+ 岗位

> [!note] 目标岗位关键词
> `AI应用开发` `AI工程师` `LLM` `大模型应用` `RAG` `智能体` `AIGC`

### 打招呼模板

```
您好，我有 X 年 Java 开发经验，近 3 个月全职转型 AI 应用开发，
已完成企业级 RAG 问答系统和多智能体项目（附演示地址）。
熟悉 Spring AI / LangChain4j / Agent / MCP，能独立设计 AI 系统架构。
看到贵司在招 AI 应用开发，希望有机会聊聊。
```

## ✅ 验收标准

- [ ] 每周 ≥ 3 个面试
- [ ] 完整讲 15 分钟项目 + 30 分钟架构题
- [ ] 目标：4-8 周内拿到 offer
