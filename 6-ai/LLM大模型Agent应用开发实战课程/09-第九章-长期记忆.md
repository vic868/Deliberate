# 📘 第9章：长期记忆

> [!abstract] 原文开篇导语（已核对）
> 大模型每次调用都是无状态的——它不记得上次说了什么，不知道你是谁，不了解你的背景。长期记忆解决这个问题，让 AI 应用在多次对话之间保持连贯、提供真正个性化的体验。原文先做分类：**会话记忆（短期）**存当前对话历史，**用户画像**存用户属性。

> [!tip] 一句话理解
> 模型本身没有记性，所谓「记得你」全靠应用在每次调用前把该带的历史、画像、旧事实重新塞进 Prompt。

## 🧩 核心概念速记

| 概念 | 一句通俗解释 |
| --- | --- |
| 会话记忆 | 只管当前这一轮对话的历史，关掉页面通常就结束了 |
| 用户画像 | 长期记录「这个用户是谁、偏好什么」，每次对话注入进 system |
| 长期记忆 | 跨会话还能调出来的事实，一般存进向量库按需检索 |
| 分层记忆架构 | 短期 / 画像 / 长期各管一层，按需要取，别一股脑全塞 |
| Token 感知截取 | 按剩余上下文预算裁剪历史，优先保住最近和最相关的内容 |
