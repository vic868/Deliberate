# 📘 第6章：RAG（检索增强生成）

> [!abstract] 原文开篇导语（已核对）
> 大模型的知识截止到训练日期，不知道你的公司文档、内部规范、最新数据。RAG 让模型能访问你的私有知识库，回答基于真实文档的问题。原文点出朴素做法的死穴：直接把所有公司文档塞进 Prompt，会超过上下文长度限制。

> [!tip] 一句话理解
> 不要让模型闭卷背答案：先去你的文档里搜出相关片段，连同问题一起交给它，相当于开卷考试。

## 🧩 核心概念速记

| 概念 | 一句通俗解释 |
| --- | --- |
| RAG | 先检索、再生成：把查到的资料垫在问题前面一起发给模型 |
| Embedding | 把文字变成一串数字（向量），意思相近的文本数字也相近 |
| 余弦相似度 | 用向量夹角衡量两段文字像不像，越像越靠前 |
| Chunking | 长文档切成小片再入库，检索才准、也不会超过上下文 |
| Rerank | 粗筛回来的候选再精排一次，把最相关的顶到前面 |
