# 四、为什么企业文档解析很难
企业文档复杂主要体现在：

```plain
1. 格式多：PDF、Word、HTML、Markdown、Excel、PPT
2. 结构多：标题、段落、表格、页眉、页脚、图片、注释
3. 质量参差：有的文档排版规范，有的很乱
4. PDF 特殊：PDF 看起来像文档，本质更像页面布局
5. 扫描件特殊：扫描 PDF 里面可能没有可提取文本
6. 表格特殊：表格里的语义依赖行列结构
7. 权限复杂：不同部门、租户、用户能看的文档不同
8. 版本复杂：同一制度可能有新版和旧版
```

---

## 【重点内容】
大家一定要理解一点。

RAG 不是技术上接个向量库就完了。

企业项目里真正麻烦的，经常是前面的文档处理。

比如你解析一个 PDF，用户肉眼看着很清楚，但程序提取出来可能是：

```plain

段
顺

全

了
```

再比如一个制度文档里有表格：

```plain

```

如果解析成普通文本后行列关系丢了，后面模型就可能理解错。

所以这一章我们要把文档解析模块做成一个工程组件，而不是随便写几行读取文件。

# 六、为什么要统一解析结构
不同文件格式解析出来不一样。

TXT：

```plain
只有纯文本。
```

Markdown：

```plain
有标题、列表、代码块。
```

HTML：

```plain
有标签、链接、页面结构。
```

Word：

```plain
有段落、标题、表格。
```

PDF：

```plain
有页码、坐标、布局。
```

如果每种格式都直接输出不同结构，后面的 Chunk 模块会非常难写。

所以要先统一成：

```plain
ParsedDocument
ParsedElement
```

后面的 Chunk 只关心统一结构，不关心原始文件是什么格式。

from dataclasses import dataclass, field
from enum import Enum
from pathlib import Path
from typing import Any, Literal


class ParsedElementType(str, Enum):
    TITLE = "title"
    PARAGRAPH = "paragraph"
    TABLE = "table"
    LIST = "list"
    CODE = "code"
    PAGE_TEXT = "page_text"
    UNKNOWN = "unknown"


class ParseStatus(str, Enum):
    SUCCESS = "success"
    PARTIAL_SUCCESS = "partial_success"
    FAILED = "failed"
    NEED_OCR = "need_ocr"
    UNSUPPORTED = "unsupported"


@dataclass
class ParsedElement:
    element_id: str
    type: ParsedElementType
    content: str
    page_number: int | None = None
    order_index: int = 0
    metadata: dict[str, Any] = field(default_factory=dict)


@dataclass
class ParsedDocument:
    document_id: str
    title: str
    source_path: str
    file_name: str
    file_type: str
    text: str
    elements: list[ParsedElement]
    status: ParseStatus
    metadata: dict[str, Any] = field(default_factory=dict)
    errors: list[str] = field(default_factory=list)


@dataclass
class ParseRequest:
    file_path: str
    tenant_id: str = "tenant_001"
    created_by: str = "system"


@dataclass
class ParseDirectoryResult:
    total: int
    success: int
    failed: int
    documents: list[ParsedDocument]


SUPPORTED_FILE_TYPES: set[str] = {
    ".txt",
    ".md",
    ".markdown",
    ".html",
    ".htm",
    ".docx",
    ".pdf",
}


def get_file_type(file_path: str | Path) -> str:
    path = Path(file_path)
    return path.suffix.lower()
```

第二个是：

```plain

# 十一、实现文本清洗 Cleaner
打开：

```plain
app/document_parsing/cleaner.py
```

写入：

```python
import re


class TextCleaner:
    def clean_text(
        self,
        text: str,
    ) -> str:
        if not text:
            return ""

        text = text.replace("\r\n", "\n")
        text = text.replace("\r", "\n")

        # 去掉过多空格。
        text = re.sub(r"[ \t]+", " ", text)

        # 连续 3 个以上换行压缩成 2 个。
        text = re.sub(r"\n{3,}", "\n\n", text)

        # 去掉每行首尾空格。
        lines = [
            line.strip()
            for line in text.split("\n")
        ]

        text = "\n".join(lines)

        return text.strip()

    def remove_repeated_lines(
        self,
        text: str,
        min_repeat: int = 3,
    ) -> str:
        """
        简单去除重复页眉页脚。

        说明：
        如果同一行在文档中重复出现很多次，可能是页眉页脚。
        这里只做教学版规则，生产环境要谨慎。
        """
        lines = [
            line.strip()
            for line in text.split("\n")
            if line.strip()
        ]

        counter: dict[str, int] = {}

        for line in lines:
            counter[line] = counter.get(line, 0) + 1

        cleaned_lines = [
            line for line in lines
            if counter.get(line, 0) < min_repeat
        ]

        return "\n".join(cleaned_lines)
```

---

## 【重点内容】
清洗这一步不要小看。

很多 PDF 会有重复页眉页脚。

很多 Word 里会有奇怪空行。

HTML 里可能有导航、脚本、样式。

解析完直接切 chunk，效果通常不好。

所以我们先做基础清洗：

```plain
统一换行
压缩空白
去掉多余空行
必要时去掉重复页眉页脚
```

但注意：

```plain
清洗不能太猛。
```

如果规则太激进，可能把真正有用的信息删掉。

# 十二、实现 Parser 基类和 TXT Parser
打开：

app/document_parsing/parsers.py
```

先写入基础代码：

```python
import hashlib
from abc import ABC, abstractmethod
from pathlib import Path

from app.document_parsing.cleaner import TextCleaner
from app.document_parsing.schemas import (
    ParsedDocument,
    ParsedElement,
    ParsedElementType,
    ParseStatus,
)


def build_document_id(
    file_path: str | Path,
) -> str:
    path = Path(file_path)

    raw = f"{path.name}:{path.stat().st_size}:{path.stat().st_mtime}"
    return hashlib.md5(raw.encode("utf-8")).hexdigest()


class BaseDocumentParser(ABC):
    def __init__(self):
        self.cleaner = TextCleaner()

    @abstractmethod
    def parse(
        self,
        file_path: str | Path,
        tenant_id: str = "tenant_001",
        created_by: str = "system",
    ) -> ParsedDocument:
        raise NotImplementedError

    def build_base_metadata(
        self,
        file_path: str | Path,
        tenant_id: str,
        created_by: str,
    ) -> dict:
        path = Path(file_path)

        return {
            "tenant_id": tenant_id,
            "created_by": created_by,
            "file_name": path.name,
            "file_size": path.stat().st_size,
            "source_path": str(path),
        }


class TxtDocumentParser(BaseDocumentParser):
    def parse(
        self,
        file_path: str | Path,
        tenant_id: str = "tenant_001",
        created_by: str = "system",
    ) -> ParsedDocument:
        path = Path(file_path)

        try:
            text = path.read_text(
                encoding="utf-8"
            )
        except UnicodeDecodeError:
            text = path.read_text(
                encoding="gbk",
                errors="ignore",
            )

        text = self.cleaner.clean_text(text)

        element = ParsedElement(
            element_id=f"{path.stem}_txt_0",
            type=ParsedElementType.PARAGRAPH,
            content=text,
            order_index=0,
            metadata={
                "parser": "TxtDocumentParser",
            },
        )

        return ParsedDocument(
            document_id=build_document_id(path),
            title=path.stem,
            source_path=str(path),
            file_name=path.name,
            file_type=path.suffix.lower(),
            text=text,
            elements=[element] if text else [],
            status=ParseStatus.SUCCESS if text else ParseStatus.FAILED,
            metadata=self.build_base_metadata(
                path,
                tenant_id,
                created_by,
            ),
            errors=[] if text else ["文本内容为空"],
        )
```

---

## 【重点内容】
TXT 最简单。

但是也要注意编码问题。

有些中文 TXT 是 UTF-8。

有些可能是 GBK。

所以这里先尝试 UTF-8，失败再用 GBK。

真实项目里可以用 `chardet` 或 `charset-normalizer` 做更稳的编码识别。

class MarkdownDocumentParser(BaseDocumentParser):
    def parse(
        self,
        file_path: str | Path,
        tenant_id: str = "tenant_001",
        created_by: str = "system",
    ) -> ParsedDocument:
        path = Path(file_path)
        raw_text = path.read_text(
            encoding="utf-8",
            errors="ignore",
        )

        elements: list[ParsedElement] = []
        current_code_lines: list[str] = []
        in_code_block = False

        lines = raw_text.splitlines()

        for index, line in enumerate(lines):
            stripped = line.strip()

            if stripped.startswith("```"):
                if not in_code_block:
                    in_code_block = True
                    current_code_lines = []
                else:
                    in_code_block = False
                    content = "\n".join(current_code_lines).strip()

                    if content:
                        elements.append(
                            ParsedElement(
                                element_id=f"{path.stem}_code_{index}",
                                type=ParsedElementType.CODE,
                                content=content,
                                order_index=len(elements),
                                metadata={
                                    "parser": "MarkdownDocumentParser",
                                },
                            )
                        )

                continue

            if in_code_block:
                current_code_lines.append(line)
                continue

            if not stripped:
                continue

            if stripped.startswith("#"):
                content = stripped.lstrip("#").strip()
                element_type = ParsedElementType.TITLE
            elif stripped.startswith(("-", "*", "+")):
                content = stripped
                element_type = ParsedElementType.LIST
            else:
                content = stripped
                element_type = ParsedElementType.PARAGRAPH

            elements.append(
                ParsedElement(
                    element_id=f"{path.stem}_md_{index}",
                    type=element_type,
                    content=content,
                    order_index=len(elements),
                    metadata={
                        "parser": "MarkdownDocumentParser",
                    },
                )
            )

        text = self.cleaner.clean_text(
            "\n\n".join(
                element.content
                for element in elements
            )
        )

        title = path.stem

        for element in elements:
            if element.type == ParsedElementType.TITLE:
                title = element.content
                break

        return ParsedDocument(
            document_id=build_document_id(path),
            title=title,
            source_path=str(path),
            file_name=path.name,
            file_type=path.suffix.lower(),
            text=text,
            elements=elements,
            status=ParseStatus.SUCCESS if elements else ParseStatus.FAILED,
            metadata=self.build_base_metadata(
                path,
                tenant_id,
                created_by,
            ),
            errors=[] if elements else ["Markdown 内容为空"],
        )
```

## 【重点内容】
Markdown 的价值在结构。

from bs4 import BeautifulSoup


class HtmlDocumentParser(BaseDocumentParser):
    def parse(
        self,
        file_path: str | Path,
        tenant_id: str = "tenant_001",
        created_by: str = "system",
    ) -> ParsedDocument:
        path = Path(file_path)

        html = path.read_text(
            encoding="utf-8",
            errors="ignore",
        )

        soup = BeautifulSoup(
            html,
            "lxml",
        )

        for tag in soup([
            "script",
            "style",
            "noscript",
            "svg",
        ]):
            tag.decompose()

        title = path.stem

        if soup.title and soup.title.string:
            title = soup.title.string.strip()

        elements: list[ParsedElement] = []

        for index, tag in enumerate(
            soup.find_all(["h1", "h2", "h3", "p", "li", "td", "th"])
        ):
            content = self.cleaner.clean_text(
                tag.get_text(" ", strip=True)
            )

            if not content:
                continue

            if tag.name in ["h1", "h2", "h3"]:
                element_type = ParsedElementType.TITLE
            elif tag.name == "li":
                element_type = ParsedElementType.LIST
            elif tag.name in ["td", "th"]:
                element_type = ParsedElementType.TABLE
            else:
                element_type = ParsedElementType.PARAGRAPH

            elements.append(
                ParsedElement(
                    element_id=f"{path.stem}_html_{index}",
                    type=element_type,
                    content=content,
                    order_index=len(elements),
                    metadata={
                        "parser": "HtmlDocumentParser",
                        "tag": tag.name,
                    },
                )
            )

        text = self.cleaner.clean_text(
            "\n\n".join(
                element.content
                for element in elements
            )
        )

        return ParsedDocument(
            document_id=build_document_id(path),
            title=title,
            source_path=str(path),
            file_name=path.name,
            file_type=path.suffix.lower(),
            text=text,
            elements=elements,
            status=ParseStatus.SUCCESS if elements else ParseStatus.FAILED,
            metadata={
                **self.build_base_metadata(
                    path,
                    tenant_id,
                    created_by,
                ),
                "html_title": title,
            },
            errors=[] if elements else ["HTML 未解析出有效正文"],
        )
```

---

## 【重点内容】
HTML 解析要先去掉：

```plain
script
style
noscript
svg
```

这些不是正文。

然后提取：

```plain
h1 / h2 / h3
p
li
td / th
```

`BeautifulSoup.get_text()` 可以把 HTML 节点文本提取出来，`separator` 参数可以控制文本拼接方式。

真实项目里，HTML 解析还会更复杂。

比如：

```plain
只保留 article
去掉导航栏
去掉 footer
保留链接

```python
from docx import Document as DocxDocument


class DocxDocumentParser(BaseDocumentParser):
    def parse(
        self,
        file_path: str | Path,
        tenant_id: str = "tenant_001",
        created_by: str = "system",
    ) -> ParsedDocument:
        path = Path(file_path)
        doc = DocxDocument(str(path))

        elements: list[ParsedElement] = []

        for index, paragraph in enumerate(doc.paragraphs):
            content = self.cleaner.clean_text(
                paragraph.text
            )

            if not content:
                continue

            style_name = (
                paragraph.style.name
                if paragraph.style
                else ""
            )

            if style_name.startswith("Heading"):
                element_type = ParsedElementType.TITLE
            else:
                element_type = ParsedElementType.PARAGRAPH

            elements.append(
                ParsedElement(
                    element_id=f"{path.stem}_docx_p_{index}",
                    type=element_type,
                    content=content,
                    order_index=len(elements),
                    metadata={
                        "parser": "DocxDocumentParser",
                        "style": style_name,
                    },
                )
            )

        for table_index, table in enumerate(doc.tables):
            rows: list[str] = []

            for row in table.rows:
                cells = [
                    self.cleaner.clean_text(cell.text)
                    for cell in row.cells
                ]

                rows.append(" | ".join(cells))

            table_text = "\n".join(rows).strip()

            if table_text:
                elements.append(
                    ParsedElement(
                        element_id=f"{path.stem}_docx_table_{table_index}",
                        type=ParsedElementType.TABLE,
                        content=table_text,
                        order_index=len(elements),
                        metadata={
                            "parser": "DocxDocumentParser",
                            "table_index": table_index,
                        },
                    )
                )

        text = self.cleaner.clean_text(
            "\n\n".join(
                element.content
                for element in elements
            )
        )

        title = path.stem

        for element in elements:
            if element.type == ParsedElementType.TITLE:
                title = element.content
                break

        return ParsedDocument(
            document_id=build_document_id(path),
            title=title,
            source_path=str(path),
            file_name=path.name,
            file_type=path.suffix.lower(),
            text=text,
            elements=elements,
            status=ParseStatus.SUCCESS if elements else ParseStatus.FAILED,
            metadata=self.build_base_metadata(
                path,
                tenant_id,
                created_by,
            ),
            errors=[] if elements else ["DOCX 未解析出有效正文"],
        )
```

---

## 【重点内容】
Word 解析重点有两个：

```plain
段落
表格
```

段落比较简单。

表格要注意，它不一定是规则二维表。

比如合并单元格、缺失单元格、嵌套表格，都会带来问题。python-docx 文档也明确说明，Word 表格不一定能自然映射成统一二维数组。

所以企业项目里，如果表格很多，建议单独设计 Table Parser。

不要把所有表格都简单拼成一段文本。

```python
import fitz


class PdfDocumentParser(BaseDocumentParser):
    def parse(
        self,
        file_path: str | Path,
        tenant_id: str = "tenant_001",
        created_by: str = "system",
    ) -> ParsedDocument:
        path = Path(file_path)
        elements: list[ParsedElement] = []
        errors: list[str] = []

        try:
            pdf = fitz.open(str(path))
        except Exception as exc:
            return ParsedDocument(
                document_id=build_document_id(path),
                title=path.stem,
                source_path=str(path),
                file_name=path.name,
                file_type=path.suffix.lower(),
                text="",
                elements=[],
                status=ParseStatus.FAILED,
                metadata=self.build_base_metadata(
                    path,
                    tenant_id,
                    created_by,
                ),
                errors=[f"PDF 打开失败：{exc}"],
            )

        for page_index in range(len(pdf)):
            page = pdf[page_index]

            try:
                page_text = page.get_text("text")
            except Exception as exc:
                errors.append(
                    f"第 {page_index + 1} 页文本提取失败：{exc}"
                )
                continue

            page_text = self.cleaner.clean_text(page_text)

            if not page_text:
                errors.append(
                    f"第 {page_index + 1} 页未提取到文本，可能是扫描件或图片页"
                )
                continue

            elements.append(
                ParsedElement(
                    element_id=f"{path.stem}_pdf_page_{page_index + 1}",
                    type=ParsedElementType.PAGE_TEXT,
                    content=page_text,
                    page_number=page_index + 1,
                    order_index=len(elements),
                    metadata={
                        "parser": "PdfDocumentParser",
                        "page_number": page_index + 1,
                    },
                )
            )

        text = self.cleaner.clean_text(
            "\n\n".join(
                element.content
                for element in elements
            )
        )

        metadata = {
            **self.build_base_metadata(
                path,
                tenant_id,
                created_by,
            ),
            "page_count": len(pdf),
        }

        pdf.close()

        if elements and errors:
            status = ParseStatus.PARTIAL_SUCCESS
        elif elements:
            status = ParseStatus.SUCCESS
        elif errors:
            status = ParseStatus.NEED_OCR
        else:
            status = ParseStatus.FAILED

        return ParsedDocument(
            document_id=build_document_id(path),
            title=path.stem,
            source_path=str(path),
            file_name=path.name,
            file_type=path.suffix.lower(),
            text=text,
            elements=elements,
            status=status,
            metadata=metadata,
            errors=errors,
        )
```

---

## 【重点内容】
PDF 是最容易出问题的格式。

因为 PDF 不是天然语义文档。

它更像一个页面布局文件。

你看到的是：

```plain
标题
正文
表格
页脚
```

但程序看到的可能是：

```plain
一堆坐标上的文字块
```

PyMuPDF 的 `page.get_text("text")` 可以提取页面纯文本，但顺序依赖 PDF 创建方式；如果是图片型文字内容，就需要 OCR。

所以本章的 PDF Parser 只做文本型 PDF。

如果解析不到文本，我们标记：

```plain
need_ocr
```

后续可以接 OCR 模块。

from pathlib import Path

from app.document_parsing.parsers import (
    BaseDocumentParser,
    DocxDocumentParser,
    HtmlDocumentParser,
    MarkdownDocumentParser,
    PdfDocumentParser,
    TxtDocumentParser,
)


class DocumentParserFactory:
    def __init__(self):
        self.parsers: dict[str, BaseDocumentParser] = {
            ".txt": TxtDocumentParser(),
            ".md": MarkdownDocumentParser(),
            ".markdown": MarkdownDocumentParser(),
            ".html": HtmlDocumentParser(),
            ".htm": HtmlDocumentParser(),
            ".docx": DocxDocumentParser(),
            ".pdf": PdfDocumentParser(),
        }

    def get_parser(
        self,
        file_path: str | Path,
    ) -> BaseDocumentParser:
        suffix = Path(file_path).suffix.lower()

        parser = self.parsers.get(suffix)

        if not parser:
            raise ValueError(
                f"暂不支持该文件类型：{suffix}"
            )

        return parser
```

---

## 【重点内容】
Factory 的作用是：

```plain
根据文件后缀选择对应 Parser。
```

这样后续 Service 不需要关心具体文件类型。

它只需要：

```python
parser = factory.get_parser(file_path)
result = parser.parse(file_path)
```

这就是工程化封装。

from pathlib import Path

from app.document_parsing.parser_factory import DocumentParserFactory
from app.document_parsing.schemas import (
    ParsedDocument,
    ParseDirectoryResult,
    ParseStatus,
    SUPPORTED_FILE_TYPES,
)


class DocumentParsingService:
    def __init__(self):
        self.factory = DocumentParserFactory()

    def parse_file(
        self,
        file_path: str | Path,
        tenant_id: str = "tenant_001",
        created_by: str = "system",
    ) -> ParsedDocument:
        path = Path(file_path)

        if not path.exists():
            return ParsedDocument(
                document_id="",
                title=path.stem,
                source_path=str(path),
                file_name=path.name,
                file_type=path.suffix.lower(),
                text="",
                elements=[],
                status=ParseStatus.FAILED,
                metadata={
                    "tenant_id": tenant_id,
                    "created_by": created_by,
                },
                errors=[f"文件不存在：{path}"],
            )

        if path.suffix.lower() not in SUPPORTED_FILE_TYPES:
            return ParsedDocument(
                document_id="",
                title=path.stem,
                source_path=str(path),
                file_name=path.name,
                file_type=path.suffix.lower(),
                text="",
                elements=[],
                status=ParseStatus.UNSUPPORTED,
                metadata={
                    "tenant_id": tenant_id,
                    "created_by": created_by,
                },
                errors=[f"暂不支持该文件类型：{path.suffix.lower()}"],
            )

        parser = self.factory.get_parser(path)

        return parser.parse(
            file_path=path,
            tenant_id=tenant_id,
            created_by=created_by,
        )

    def parse_directory(
        self,
        directory: str | Path,
        tenant_id: str = "tenant_001",
        created_by: str = "system",
    ) -> ParseDirectoryResult:
        directory_path = Path(directory)

        documents: list[ParsedDocument] = []

        if not directory_path.exists():
            return ParseDirectoryResult(
                total=0,
                success=0,
                failed=0,
                documents=[],
            )

        files = [
            path for path in directory_path.rglob("*")
            if path.is_file()
            and path.suffix.lower() in SUPPORTED_FILE_TYPES
        ]

        for file_path in files:
            documents.append(
                self.parse_file(
                    file_path=file_path,
                    tenant_id=tenant_id,
                    created_by=created_by,
                )
            )

        success_count = sum(
            1 for doc in documents
            if doc.status in [
                ParseStatus.SUCCESS,
                ParseStatus.PARTIAL_SUCCESS,
            ]
        )

        failed_count = len(documents) - success_count

        return ParseDirectoryResult(
            total=len(documents),
            success=success_count,
            failed=failed_count,
            documents=documents,
        )


document_parsing_service = DocumentParsingService()
```

    type: str
    content: str
    page_number: int | None = None
    order_index: int
    metadata: dict


class ParsedDocumentResponse(BaseModel):
    document_id: str
    title: str
    source_path: str
    file_name: str
    file_type: str
    text: str
    status: str
    metadata: dict
    errors: list[str]
    elements: list[ParsedElementResponse]


@router.post(
    "/documents/parse",
    response_model=ApiResponse[ParsedDocumentResponse],
)
async def parse_document(
    file: UploadFile = File(...),
    tenant_id: str = "tenant_001",
    current_user: CurrentUser = Depends(get_current_user),
) -> ApiResponse[ParsedDocumentResponse]:
    safe_file_name = Path(file.filename or "uploaded_file").name
    target_path = UPLOAD_DIR / safe_file_name

    with target_path.open("wb") as buffer:
        shutil.copyfileobj(
            file.file,
            buffer,
        )

    result = document_parsing_service.parse_file(
        target_path,
        tenant_id=tenant_id,
        created_by=current_user.user_id,
    )

    response = ParsedDocumentResponse(
        document_id=result.document_id,
        title=result.title,
        source_path=result.source_path,
        file_name=result.file_name,
        file_type=result.file_type,
        text=result.text,
        status=result.status.value,
        metadata=result.metadata,
        errors=result.errors,
        elements=[
            ParsedElementResponse(
                element_id=element.element_id,
                type=element.type.value,
                content=element.content,
                page_number=element.page_number,
                order_index=element.order_index,
                metadata=element.metadata,
            )
            for element in result.elements
        ],
    )

    return ApiResponse[ParsedDocumentResponse](
        data=response
    )
```

# 三十二、为什么扫描 PDF 需要 OCR
扫描 PDF 本质上可能是一张图片。

你肉眼看到文字，但 PDF 内部没有文本层。

普通 `page.get_text()` 只能提取 PDF 里存在的文本层。

如果页面内容是图片，就需要 OCR。

PyMuPDF 文档也说明，图片型文本内容需要使用 OCR 后再进行文本提取；其 OCR 能力依赖 Tesseract。

---

## 【重点内容】
这里要讲清楚。

不是所有 PDF 都能直接解析。

如果用户上传扫描版合同，你用普通 PDF 文本提取可能什么都拿不到。

这不是你的代码一定错了。

而是 PDF 里面本身没有文本。

这时要走 OCR 流程。

本课程主线先不做 OCR，因为 OCR 牵涉：

```plain
图片预处理
语言模型
识别准确率
版面分析
表格识别
成本
性能
```

后续企业级扩展可以接入 OCR。

# 四十八、面试回答：企业文档解析怎么做
## 回答话术一：基础版
```plain
企业知识库里的文档解析，是 RAG 入库链路的第一步。

它的目标是把 PDF、Word、Markdown、HTML、TXT 等不同格式的文档，统一解析成标准结构，比如 ParsedDocument 和 ParsedElement。

ParsedDocument 保存文档标题、正文、文件类型、来源路径、metadata 和解析状态；ParsedElement 保存标题、段落、表格、页码和顺序。这样后面的 Chunk、Embedding 和检索模块就不用关心原始文件格式。
```

---

## 回答话术二：项目版
```plain
在项目里，我会把文档解析单独封装成 DocumentParsingService。

它内部通过 ParserFactory 根据文件类型选择不同 Parser，比如 TxtParser、MarkdownParser、HtmlParser、DocxParser、PdfParser。

解析结果统一输出 ParsedDocument。PDF 会按页提取文本并保留 page_number；Word 会提取段落和表格；HTML 会去掉 script 和 style，只保留正文标签；Markdown 会保留标题、列表和代码块结构。

解析完成后不会直接入向量库，而是先做清洗和质量检查，再进入 Chunk 切分流程。
```

---

## 回答话术三：工程版
```plain
工程上我比较关注几个点。

第一，解析结果必须结构化，不能只是一段纯文本。

第二，metadata 必须完整，比如 tenant_id、department、doc_type、version、source_path、page_number，否则后面做权限过滤和来源引用会很困难。

第三，PDF 解析要区分文本型 PDF 和扫描型 PDF。如果 page.get_text 提取不到内容，不能直接当空文档，而应该标记 need_ocr。

第四，表格要尽量保留结构，因为企业制度、价格表、SLA 这类信息经常在表格里。

第五，大文件解析最好异步化，上传接口只返回 document_id，后台任务处理解析、切分和入库。
```

# 四十九、面试回答：PDF 解析为什么难
```plain
PDF 难点在于，它不是天然的语义文档，而更像页面布局。

同样一个 PDF，人看起来是标题、段落和表格，但程序拿到的是页面上的文字块、坐标和绘制顺序。所以提取出来的文本可能顺序混乱、表格结构丢失、页眉页脚重复。

另外，扫描版 PDF 里面可能根本没有文本层，只是一张图片。这种情况下普通文本提取拿不到内容，需要 OCR。

所以我会在解析结果里保留 page_number、parse_status、errors，如果发现页面没有文本，就标记 need_ocr，后续走 OCR 或人工处理流程。
```

# 五十、面试回答：文档解析和 Chunk 的关系
```plain
文档解析和 Chunk 是上下游关系。

文档解析负责把原始文件转成统一结构，比如 ParsedDocument 和 ParsedElement。

Chunk 切分负责基于解析后的结构进行切分，比如按标题切、按段落切、按页切、按表格切。

如果解析阶段没有保留标题、页码、表格和段落顺序，Chunk 阶段就只能硬切文本，效果会差很多。

所以一个好的 RAG 系统，不是直接对原始文件切 chunk，而是先结构化解析，再根据结构切分。
```

# 六十四、本章总结
## 【重点内容】
好了，到这里，第 40 章我们就讲完了。

这一章我们讲的是企业文档解析。

大家一定要记住：

```plain
RAG 的第一步不是向量数据库，
而是把企业文档稳定解析成结构化文本。
```

这一章我们做了：

```plain
TXT 解析
Markdown 解析
HTML 解析
Word DOCX 解析
PDF 解析
目录批量解析
上传解析接口
```

我们还设计了统一结构：

```plain
ParsedDocument
ParsedElement
ParseStatus
```

这样后面的 Chunk、Embedding、Retriever 都可以基于统一结构继续处理。

最后再强调几个关键点：

```plain
1. PDF 不一定能直接解析，扫描件要 OCR
2. 表格不要轻易丢弃
3. metadata 一定要从解析阶段开始保存
4. 文档权限和版本要尽早进入 metadata
5. 解析失败不能静默吞掉，要有 status 和 errors
6. 大文件解析建议异步化
```

文档解析做不好，后面 RAG 很难准。

文档解析做扎实，后面的 Chunk 和向量入库才有基础。
