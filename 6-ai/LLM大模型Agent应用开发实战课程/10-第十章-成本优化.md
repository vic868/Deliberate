## 🧩 核心概念速记

| 概念 | 一句通俗解释 |
| --- | --- |
| 精确缓存 | 一模一样的问题直接返回上次答案，用 MD5 当 key，命中率最实在 |
| 语义缓存 | 意思相近的问题也命中缓存，靠向量相似度判断，命中率更高但要防误判 |
| 分级缓存 | 内存 / Redis / 持久化按热度分层放，热的秒回、冷的慢慢取 |
| 令牌桶限流 | 按速率发令牌，没令牌就排队，防止被刷爆账单 |
| 成本监控 | 按模型、按用户、按时间段统计 token 与花费，超预算就告警 |
