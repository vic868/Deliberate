## 🧩 核心概念速记

| 概念 | 一句通俗解释 |
| --- | --- |
| 统一配置管理 | 环境变量集中在一处读，业务代码不直接碰 process.env |
| Mock 模型调用 | 测试时把真模型换成假的，省钱、快、结果还能稳定复现 |
| 模型抽象层 / 工厂 | 换模型只改一处，上层业务代码完全不感知 |
| 熔断器 | 某模型连续出错就暂时断开，别一直往失败的地方发请求 |
| Prompt A/B 测试 | 两版提示词同时跑，用真实数据决定留哪版，而不是靠感觉 |
