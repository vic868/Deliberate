## 🧩 核心概念速记

| 概念 | 一句通俗解释 |
| --- | --- |
| 多阶段构建 | 编译用一个镜像、运行用另一个，最终镜像更小也更安全 |
| 指数退避重试 | 失败后等 1s、2s、4s…再试，别把对面服务打挂 |
| 降级策略 | 主模型挂了就自动换备用模型或返回兜底答案，保证不白屏 |
| 链路追踪 | 一个 trace id 串起整条调用链，出问题时能定位卡在哪一步 |
| Prompt 注入防护 | 把用户输入当数据而不是指令，别让「忽略以上要求」得逞 |
