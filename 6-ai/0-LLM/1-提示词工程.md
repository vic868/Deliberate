# 1-提示词工程

> [!abstract] 一句话概述
> 首先，介绍基础提示词设计与优化，帮助开发者理解如何与大模型对话
> 其次，深入讲解思维链、自我反思等高级提示技术，提升模型推理与复杂任务处理能力
> 最后，介绍提示模板设计与管理，实现提示的复用、版本控制和动态生成。

> [!tip] 提示词基本结构
> 1. 系统提示词
> 2. 用户输入
> 3. 历史消息
> 合理的设计提示内容和格式能够显著提升模型的准确性和可控性。

---

## 🗂️ 提示词的设计原则

| 项目        | 内容                       |
| --------- | ------------------------ |
| 📌 明确性    | 用户清晰、任务具体、避免歧义           |
| 🏷️ 上下文丰富 | 补充必要的背景信息，减少模型误解         |
| 🔗 输出格式约束 | 通过示例、JSON 格式要求等方式，规范输出结构 |
| 📍 逐步引导   | 复杂任务可拆解为多步提示，逐步引导模型思考    |

------


## 🗂️提示词优化技巧

| 项目               | 内容                 |
| ---------------- | ------------------ |
| 💰增加少量示例         | 引导模型模仿特定风格或格式。     |
| 明确输出格式。          | 例如，请用 Json 格式返回结果。 |
| 针对模型幻觉，增加事实核查要求。 |                    |
**基础提示设计是 LM 应用的第一步。合理的结构与优化技巧能极大提升模型的实用性和可控性，开发者应根据任务需求灵活调整提示内容和格式。**

---
## 高级提示技术（思维链和自我反省）

### 1、思维链
思维链是一种通过引导模型分步思考，提升复杂推理任务准确性的提示技术。通过在提示中加入“请一步步思考并展开你的推理过程”，模型会输出详细的中间推理步骤，减少错误。

### 2、自我反思
自我反思提示，让模型在输出答案之后主动地检查和修正自己的推理过程，这对减少模型幻觉、提升答案可靠性非常有效。

 **思维链和自我反思等高级提示技术能有效提升 LM 的复杂推理、事实核查等场景下的表现。开发者应根据任务复杂度灵活采用这些方法，增强 Agent 的智能水平。**
