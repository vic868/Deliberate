# 0-LLM

> [!abstract] 一句话概述
> LLM 虽然具备强大的语言理解、推理、生成能力，但也存在着幻觉、事实准确性不足、上下文长度有限的问题。实际应用需要结合 RAG、外部工具调用等方式增强其能力。
> LM 的核心能力：
> 1. 自然语言理解与上下文建模能力。
> 2. 二、知识整合与推理能力。
> 3. 丰富多样的生存能力。
> 4. 强大的任务泛化能力。



> [!tip] ❌LLM 的典型局限性逐项剖析。
> 1. 幻觉问题：幻觉是指 LM 在缺乏事实依据的情况下，也会生成看似合理但实为虚假的信息。
> 2. 事实准确性与知识遗忘：LLM 的知识库实际上是其训练文本的统计表达，无法主动获取新知识。知识库在快照时刻的时间之后。此外，对于训练中没有覆盖的知识领域，模型往往会构造或迁移错误信息。
> 3. 上下文窗口长度受限。
> 4. 多轮推理与工具实践能力受限。LLM 在单次输入输出的基础上的推理能力较强，但面对复杂的多步推理、分阶段决策和工具调用的任务，原生 LLM 的 CoT 灵活性和准确性仍有限。这使得其在规划执行--记忆能力的泛用性上受限，往往需要借助特定的范式优化和外部工具进行强化。往往需要借助特定的范式优化和外部工具进行强化。
> 5. 可控性和稳定性不足：
LLM 生成模型模式本身是概率采样，受 prompt、随机种子、温度等影响，输出结果具有不确定性。在实际过程中，若需要实现精准可控、符合业务约束的输出，往往需要复杂的 prompt 设计和 Agent 管理机制。
