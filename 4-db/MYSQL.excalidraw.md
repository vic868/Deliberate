## Text Elements
MYSQL 数量指标 ^CBre3rQ7

一张表理论上最多存储 4096 列 ^O8cj3fp7

mysql server 层的 4096 是写死在代码里的常量，这个数字为兼容各种存储引擎和内部数据结构设计的上限 ^1h7pFBe9

1.行大小限制 ^i6RXnVT6

一行数据最多 65535 字节，所有列的存储开销加起来不能超过这个上限 ^QCEeHaVk

2.存储引擎的限制 ^sDbmCLoa

InnoDB引擎的硬限制是 1017 列，比理论值低很多，这是因为 InnoDB内部要为第一列维护元数据，列太多会导致内部结构膨胀 ^IxMjHsCm

InnoDB的 1017 列限制更底层一些，InnoDB的行
格式里有一个叫“filed start offsets”的数组，用来记录
每个字段的起始位置，这个数组的设计限制了最多支持
1017 列个用户可见列。 ^BbT9jFBe
