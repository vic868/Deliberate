# 06 · 团队管理：授权、1on1 与向上汇报

> 管理者的三块基石：**向下（带人）、平行（协作）、向上（汇报）**。
> 工具比态度靠谱：有模板，管理就不靠"悟"。

## 一、授权：不是甩锅，是"有梯度地放手"

### 授权阶梯（对不同人用不同级）

| 级别 | 说法 | 适用 |
|---|---|---|
| L1 指示 | "你去做，按我说的" | 新手 / 紧急事故 |
| L2 建议 | "你先出个方案我看看" | 有想法但没把握 |
| L3 确认 | "你决定，动手前跟我对一下" | 基本胜任 |
| L4 授权 | "你全权决定，只需同步结果" | 骨干 / 他比你懂 |

**授权四件套（缺一不可）**：
1. **目标与边界**：交付物 + 验收标准 + 红线（预算/权限/时间）
2. **资源**：给时间、给人、给信息，不给资源的授权是甩锅
3. **节奏**：约定同步频率（"每周三对一次"），**只看里程碑不盯过程**
4. **兜底**：明确"随时可以升级找我"，失败不追责但要复盘

> 反模式：授权后又事事插手（等于没授权）、只授权不给资源、出了事才出现。

## 二、1on1：一对一沟通模板（每 1–2 周一次，30 分钟）

**原则：这是下属的议程，不是你的进度检查。**

| 时长 | 板块 | 说什么 |
|---|---|---|
| 5' | 近况 | "这周最顺/最堵的是什么？" |
| 10' | 障碍 | 需要我清掉什么墙？（你的核心职责=清障） |
| 10' | 成长 | 想往哪个方向走？我能给什么机会/反馈？ |
| 5' | 反馈 | 用 **SBI**（情境-行为-影响），具体到事 |
| 结束 | Action | 各自 1–2 条待办，下次 1on1 先复盘 |

**万能开场**："最近怎么样？有什么我能帮你清障的？" —— 记住管理者在 1on1 里的角色是 **servant leader**。

## 三、反馈与辅导

### SBI 反馈模型（表扬和批评通用）
```
S 情境：周二的线上事故（When/Where）
B 行为：你第一时间拉群同步、10 分钟内给出回滚方案（具体动作，不贴标签）
I 影响：客服投诉量减少七成，客户情绪稳定（对团队/业务的影响）
```
> 禁语："你总是…" "你这个人…" —— 对事不对人，行为可改变，人格不可。

### GROW 辅导（下属来问"怎么办"时，别直接给答案）
- **G 目标**：你想要的结果是什么？
- **R 现状**：现在卡在哪？
- **O 方案**：你有哪几个选项？各有什么代价？
- **W 行动**：你决定做什么？什么时候做？需要我什么支持？

## 四、会议节奏（管理者的"心跳"）

| 会议 | 频率 | 时长 | 唯一目的 | 纪律 |
|---|---|---|---|---|
| 站会 | 每日 | ≤15' | 暴露阻塞 | 只讲"昨天/今天/卡点"，讨论会后另开 |
| 周例会 | 每周 | 45–60' | 对齐里程碑与偏差 | 看燃尽图，只聊偏差和风险 |
| 1on1 | 1–2 周 | 30' | 清障 + 成长 | 下属的议程 |
| 月度复盘 | 每月 | 60–90' | GRAI 闭环 | 必须产出"改进项 + Owner + 期限" |

> 铁律：**没有议程不开会，没有 Owner 的决议不算决议，没有复盘的会议白开。**

## 五、向上管理：让老板省心的三件事

### 1. 管理期望
- 接任务时用 **5W1H** 当场对齐（What/When/How much），**模糊的期望 = 日后的锅**。
- 定期主动同步"基准线变了没有"，别等老板来问。

### 2. 带着方案汇报（PREP）
```
【P】我建议走 A 方案。
【R】因为现在最大的约束是时间，A 能保住 11/20 上线。
【E】上季度 XX 项目同样情况下用 A 按时交付；B 要多 3 周和 2 个人。
【P】所以建议 A，需要您在周五前拍板，否则影响下游联调。
```

### 3. 三类消息用三种姿势
| 消息类型 | 姿势 | 例 |
|---|---|---|
| 进展 | 一句话 + 数据 | "按计划，里程碑 3 完成，SPI 1.02" |
| 风险 | 提前！带预案 | "有 X 风险，影响 Y，我有 A/B 两个预案，建议 A" |
| 坏消息 | **第一时间** + 补救方案 | 永远别让老板从别人嘴里听到坏消息 |

### 向上汇报的禁区
- ❌ 只讲过程不讲结论
- ❌ 带着问题去（要答案）而不是带着方案去（要决策）
- ❌ 报喜不报忧 / 拖到 deadline 才说
- ❌ 越级汇报绕开直属上级
