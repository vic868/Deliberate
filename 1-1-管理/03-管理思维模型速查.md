# 03 · 管理思维模型速查表

> 不需要全会，先掌握 ⭐ 的 6 个，其余按场景查。
> 使用原则：**一个场景只用一个主模型**，别为了套模型而套模型。

## 一、目标类

| 模型 | 一句话 | 什么时候用 | 例句 |
|---|---|---|---|
| ⭐**SMART** | 目标要具体、可衡量、可达成、相关、有时限 | 定 KPI、定任务目标 | "把接口可用性提到 99.95%，Q4 前达成" |
| **OKR** | 目标 + 关键结果，对齐与聚焦 | 季度规划、上下对齐 | "O：大促 0 重大故障；KR1：压测 3 倍峰值通过" |
| ⭐**四象限**（重要紧急） | 重要不紧急的事才是管理者主战场 | 每日/每周排序 | "救火 vs 建机制" |
| **MoSCoW** | Must/Should/Could/Won't 需求分级 | 需求评审、范围谈判 | "M 必须做，W 这期明确不做" |
| **二八定律** | 20% 因素决定 80% 结果 | 找杠杆点、砍无效工作 | "先保 Top3 核心链路" |

## 二、拆解与分析类

| 模型 | 一句话 | 什么时候用 |
|---|---|---|
| ⭐**WBS** | 以交付物为导向层层拆到工作包 | 立项、排期、分活（详见 [[02-结构化思维-5W1H与任务拆解]]） |
| **MECE** | 相互独立、完全穷尽 | 分类、查漏、写方案 |
| ⭐**金字塔原理** | 结论先行，以上统下，归类分组，逻辑递进 | 写报告、口头汇报、邮件 |
| **5Why / 鱼骨图** | 连问为什么直到机制层 | 事故复盘、质量问题 |
| **5W1H** | 把问题要素问全 | 接活、描述问题（详见 [[02-结构化思维-5W1H与任务拆解]]） |
| **第一性原理** | 回到最基本的事实重新推导 | 打破"一直这么做"的惯性 |

## 三、执行与监控类

| 模型 | 一句话 | 什么时候用 |
|---|---|---|
| ⭐**PDCA** | 计划-执行-检查-处理，持续循环 | 一切带改进性质的工作 |
| **RACI** | 谁执行/谁负责/被咨询/被告知 | 跨团队分工，避免三不管 |
| **里程碑 + 燃尽图** | 用节点和曲线看偏差 | 项目例会盯进度 |
| **关键路径** | 最长链路决定工期 | 排期压缩、砍时间砍哪里 |
| **缓冲/储备** | 应急储备(已知风险) vs 管理储备(未知风险) | 承诺日期前 |
| **风险矩阵** | 概率 × 影响定级 | 风险评审、上报优先级 |

## 四、复盘类

| 模型 | 一句话 | 模板 |
|---|---|---|
| ⭐**GRAI** | 目标-结果-分析-改进 | 四段式复盘会 |
| **ARR / 事前验尸** | 事前反向推演"为什么会失败" | 立项风险讨论 |
| **KPT** | Keep/Problem/Try | 轻量迭代回顾 |
| **经验教训登记册** | 复盘不入库 = 白复盘 | PMP 组织过程资产 |

## 五、人与领导力类

| 模型 | 一句话 | 什么时候用 |
|---|---|---|
| ⭐**情境领导** | 按下属成熟度切换告知/教练/支持/授权 | 带人、分配任务 |
| **授权阶梯** | 指示 → 建议 → 确认 → 授权 | 决定放多少手（详见 [[06-团队管理-授权1on1与向上汇报]]） |
| **塔克曼五阶段** | 组建-风暴-规范-执行-解散 | 判断团队阶段、容忍风暴期冲突 |
| **SBI 反馈** | 情境-行为-影响 | 表扬与批评，对事不对人 |
| **GROW** | 目标-现状-方案-行动 | 1on1 辅导、激发主动性 |
| **乔哈里视窗** | 公开/盲区/隐藏/未知 | 给反馈、做 360 评估 |
| **冲突五法** | 合作>妥协>缓和>强迫>撤退 | 处理人际与团队冲突（详见 [[../PMP学习/PMP场景整理|PMP 场景整理]]） |
| **马斯洛 / 双因素** | 先消除不满，再给成就感 | 激励设计、留人 |

## 六、沟通与汇报类

| 模型 | 一句话 | 什么时候用 |
|---|---|---|
| ⭐**PREP** | 观点-理由-例子-重申观点 | 60 秒即兴发言 |
| **STAR** | 情境-任务-行动-结果 | 讲案例、面试、写绩效 |
| **电梯演讲** | 30 秒讲清一件事 | 向上争取资源 |
| **干系人权力/利益矩阵** | 高权力高利益者重点管理 | 排沟通精力 |
| **向上管理** | 带方案不带问题，管理老板预期 | 日常汇报 |

## 七、决策与战略类

| 模型 | 一句话 | 什么时候用 |
|---|---|---|
| **SWOT** | 优势/劣势/机会/威胁 | 阶段性盘点 |
| **决策矩阵** | 多维度加权打分 | 技术选型、方案对比 |
| **成本收益分析 / ROI** | 一切决策翻译成钱和价值 | 说服老板、砍需求 |
| **飞轮效应** | 找到能自我强化的循环 | 想"体系化"而非"一次性"的事 |

## 八、组合拳（记不住就背这条流水线）

```
接活：5W1H 澄清
 → 定目标：SMART
 → 拆活：WBS + MECE
 → 排优先级：四象限 / MoSCoW
 → 分活：RACI
 → 干活：PDCA + 里程碑
 → 汇报：金字塔 / PREP
 → 复盘：GRAI → 沉淀进模板
```

## 九、什么时候用哪个？（场景索引）

| 你遇到的情况 | 直接翻到 |
|---|---|
| 老板问"这事儿怎么样了" | PREP + 金字塔 |
| 需求永远做不完 | MoSCoW + 四象限 |
| 项目要延期了 | 关键路径 + 缓冲 + 风险上报 |
| 出了事故要甩锅/追责 | 5Why + GRAI（对事不对人） |
| 下属来问"这个怎么做" | 情境领导 + GROW（别直接给答案） |
| 跨部门没人听你的 | RACI + 干系人矩阵 + 合作式冲突解决 |
| 不知道先干哪件 | 四象限 + 二八定律 |
