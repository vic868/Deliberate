# 04 · PMP 速查：五大过程组 × 十大知识领域

> 定位：考试的骨架 + 日常管理的翻译器。考试技巧见 [[../PMP学习/PMP场景整理|PMP 高频场景整理]]。
> 高大上的用法：**把日常工作"挂"到过程组上说** —— "这属于规划过程组的定义活动，输出了 WBS 和里程碑计划"。

## 一、五大过程组（项目生命周期的心跳）

| 过程组 | 干什么 | 关键输出 | 日常对应 |
|---|---|---|---|
| **启动** Initiation | 立项、任命 PM、明确目标 | **项目章程**、干系人登记册 | "这事立项了、谁拍板、成功标准是啥" |
| **规划** Planning | 定范围/进度/成本/质量/风险… | **项目管理计划**（基准） | 排期、拆 WBS、定预算、识别风险 |
| **执行** Executing | 带人干活、整合资源 | 可交付成果、变更请求 | 开发、协调、团队建设 |
| **监控** M&C | 对比基准、发现偏差、纠偏 | 绩效报告、变更请求 | 站会盯进度、质量检查、风险再评估 |
| **收尾** Closing | 验收、归档、释放资源 | **验收报告**、经验教训 | 上线总结、复盘入库、人员释放 |

> 口诀：**启动定章程，规划定计划，执行出成果，监控找偏差，收尾要验收**。
> 两个高频考点：① 变更永远从**监控/执行**提出 → 进**整体变更控制** → 批了才改基准；② **收尾不能省**，不验收不归档不算项目结束。

## 二、十大知识领域（PM 的十个抽屉）

| # | 领域 | 核心问题 | 关键工具/概念 |
|---|---|---|---|
| 1 | **整合** Integration | 怎么把所有事串起来、谁说了算 | 项目章程、变更控制、整合变更控制 |
| 2 | **范围** Scope | 做什么、**不做什么** | WBS、范围说明书、100% 原则 |
| 3 | **进度** Schedule | 什么时候做完 | 关键路径、甘特、里程碑、资源平滑 |
| 4 | **成本** Cost | 花多少钱 | 挣值 EVM（PV/EV/AC、SPI、CPI）、储备 |
| 5 | **质量** Quality | 做到什么标准 | 质量审计、测试、因果图、PDCA |
| 6 | **资源** Resource | 谁来干、怎么让人发挥 | 资源日历、RACI、团队发展、谈判 |
| 7 | **沟通** Communication | 谁在什么频率以什么方式知道什么 | 沟通管理计划、推拉式沟通 |
| 8 | **风险** Risk | 可能出什么事、怎么办 | 风险登记册、定性/定量分析、应对策略 |
| 9 | **采购** Procurement | 外包/采购怎么管 | 合同类型（FFP/CPFF/T&M）、招标 |
| 10 | **干系人** Stakeholders | 谁受影响、怎么让他们满意 | 权力/利益矩阵、参与计划 |

> 记法：**"人（干系人/沟通/资源）财物（成本/采购）时（进度）空（范围/质量）风控整"** —— 自己编个顺口溜更牢。

## 三、挣值（EVM）—— 高大上指数最高的一页

| 缩写 | 全称 | 含义 |
|---|---|---|
| PV | Planned Value | 到今天**计划**该花的钱/该完成的量 |
| EV | Earned Value | 到今天**实际完成**的量值多少钱 |
| AC | Actual Cost | 到今天**实际花**了多少钱 |
| SPI = EV/PV | 进度绩效 | <1 = 慢了 |
| CPI = EV/AC | 成本绩效 | <1 = 超支了 |
| EAC = BAC/CPI | 完工估算 | 按当前效率，最后要花多少 |

**汇报例句**："项目中期 SPI 0.92、CPI 1.05，进度滞后 8% 但成本可控，已通过赶工（ crashing ）压缩关键路径，预计完工偏差收敛到 3% 以内。" ← 这一句就够高大上。

## 四、PMP ↔ 日常管理翻译表

| 你平时说的话 | PMP 黑话 |
|---|---|
| "先说清楚做啥不做啥" | 定义范围、创建 WBS |
| "排个计划表" | 定义活动、排列活动顺序、估算持续时间 |
| "拉个群同步一下" | 规划沟通管理 |
| "先想想可能出什么事" | 识别风险、定性分析 |
| "这事我拍不了板" | 整体变更控制 / 上报发起人 |
| "做完总结一下" | 管理项目知识、经验教训登记册 |
| "谁该干啥别扯皮" | RACI、责任分配矩阵 |
| "验收上线" | 确认范围 + 收尾 |

## 五、等成绩期间的行动清单

- [ ] **成绩解读准备**：AT/T/BT/NI 四档，3A/2A 什么水平（通过线约 60%+，三个领域全 AT 是高分）
- [ ] **证书准备**：通过后下载电子证书；纸质证书由 PMI 寄送；证书 **3 年有效**
- [ ] **PDU 规划**：3 年周期内攒 **60 PDU**（教育类 35 + 实践贡献 25 的大致结构），到期前完成 CCR 申报续证
- [ ] **把知识落地**：从本目录挑 3 个模型（建议 WBS + 风险登记册 + 经验教训）在当前工作里真用一次 —— **面试时"我用过"远比"我学过"值钱**
- [ ] **面试话术储备**："PMP 不只是证书，它给了我一套把模糊的管理动作变成可交付、可监控、可复盘的标准化语言。"
