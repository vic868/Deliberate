# AI 学习规划

> 定位：**AI 应用开发方向 · 目标岗位：AI 开发总监 / AI 技术负责人**
> 现状：Java 背景 · 目前待业 · 需要**快速**精通 AI 应用开发

## 为什么是这个定位

- **Java 是优势**：企业级 AI 应用落地（RAG、Agent、工作流）大多跑在 Spring 生态上，Java 工程师是稀缺的"能把 AI 接到业务里"的人，而不是只会调 API 的人。
- **开发总监/技术负责人**比拼的不是训练模型，而是：
  1. 能设计企业级 AI 系统架构（检索、Agent、多模型、成本、安全）
  2. 能把 AI 能力落地成业务价值
  3. 能搭建团队、定技术方向、写技术方案
- 因此本规划 **不学炼丹（训练模型）**，聚焦 **AI 应用工程化 + 架构 + 技术领导力**。

## 核心原则

1. **80% 时间写代码，20% 时间看理论** —— 不陷入原理深坑
2. **周周有产出** —— 每阶段结束必须有可演示的项目/代码
3. **以终为始** —— 一切围绕"12 周后能拿 offer"展开
4. **记录复盘** —— 每天在本目录打卡，沉淀到 Obsidian
