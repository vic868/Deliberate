# 阶段一 基础入门（3 天）

> [!quote] 本阶段目标
> 从 0 到 1 打通认知，能独立调通 LLM API。**够用就行，重点"能跑通代码"。**

## 必须搞懂的概念

> [!tip] 概念表 —— 每个都要能用一句话给非技术人员讲清

| 概念 | 一句话理解 | 为什么重要 |
| --- | --- | --- |
| Token | 文本最小单位（≈1 汉字 = 1-2 token） | 计费与长度限制 |
| Context Window | 模型一次能"看"的上下文 | 决定喂多少文档 |
| Temperature | 输出随机性 | 客服低、创作高 |
| Top-p | 概率截断采样 | 与 temperature 二选一 |
| 幻觉 | 一本正经地编造 | RAG 与评估要解决的核心 |
| Embedding | 文本→向量，相似度检索 | RAG 的地基 |
| 预训练/微调/提示工程 | 三个层次让模型干活 | 多数场景提示工程就够 |
| Function Calling | 模型决定调用哪个函数 | Agent 核心机制 |

## 结构化 Prompt 模板

````markdown
> [!example] 万能模板
> 你是一位 [角色]，擅长 [领域]。
> 背景：{相关上下文}
> 任务：{具体要做的事}
> 要求：
> 1. {约束一}
> 2. {约束二}
> 3. 输出格式：{JSON/列表/表格}
> 示例：{给 1-2 个例子}
> 信息不足时请直接说明，不要编造。
````

## 📋 每日任务

### Day 1 · 概念扫盲
- [ ] 看 1 篇 LLM 科普（李沐《Transformer 精读》或同类）

### Day 3 · API 实战

- [ ] **交付：命令行聊天机器人 demo**
