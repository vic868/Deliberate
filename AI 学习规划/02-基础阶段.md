# 阶段一 基础入门（第 1 周）

> 从 0 到 1 打通认知，能独立调通 LLM API。
> 本阶段不必太深，够用就行，重点是"能跑通代码"。

## 必须搞懂的概念（用自己的话复述）

| 概念 | 一句话理解 | 为什么重要 |
| --- | --- | --- |
| Token | 模型处理文本的最小单位（约 1 个汉字 ≈ 1-2 token） | 计费、长度限制都靠它 |
| Context Window | 模型一次能"看"的上下文长度 | 决定你能喂多少文档 |
| Temperature | 控制输出随机性/创造性 | 客服要低、写文案要高 |
| Top-p | 采样的概率截断 | 与 temperature 二选一调节 |
| 幻觉 | 模型一本正经地编造内容 | RAG 与评估要解决的核心问题 |
| Embedding | 把文本变成向量，用于相似度检索 | RAG 的地基 |
| 预训练 / 微调 / 提示工程 | 三个层次地让模型干活 | 绝大多数场景提示工程就够 |
| Function Calling | 让模型决定调用哪个函数 | Agent 与工具的核心机制 |

## 结构化 Prompt 模板（背下来直接用）

```
你是一位 [角色]，擅长 [领域]。
背景：{相关上下文}
任务：{具体要做的事}
要求：
1. {约束一}
2. {约束二}
3. 输出格式：{JSON / 列表 / 表格}
示例：{给 1-2 个例子}
如果信息不足，请直接说明，不要编造。
```

## 常见误区
1. ❌ 一上来啃 Transformer 论文 —— 本阶段只需要"知其然"
2. ❌ 收藏一堆课程不行动 —— 每学完立刻写代码或写笔记
3. ❌ 只抄别人的 Prompt —— 自己设计才有手感
