# 阶段四 项目与求职（第 9-12 周）

> 把能力变成 offer。一切以"拿到面试 → 拿到 offer"为唯一目标。

## 第 9 周 项目打磨

- [ ] 选定 2-3 个代表作（见 [[实战项目]]）
- [ ] 每个项目补齐：
  - README：背景、架构图、技术亮点、量化指标、演示地址
  - 代码注释整洁、结构清晰，敢让面试官看
- [ ] 部署到免费云（如阿里云/腾讯云/自建），确保线上可演示
- [ ] 录 2 分钟演示视频（手机录屏即可）

## 第 10 周 简历与作品集

### 简历重写要点（对标总监/负责人）
1. **标题写定位**：资深 Java 工程师 · AI 应用开发方向
2. 项目经历量化：`效果`用数字（回答准确率 85%→93%、成本下降 60%）
3. 突出：Spring AI、RAG、Agent、系统设计、团队管理经验（哪怕带过 1-2 人）
4. 技术栈关键词：Spring Boot、Spring AI、LangChain4j、向量数据库、LLM API、Agent、MCP

### 作品集
- [ ] 技术博客 2-3 篇（可发掘金/CSDN/公众号）：
  - 《Java 工程师如何快速上手 AI 应用开发》
  - 《从 0 到 1 搭一个企业级 RAG 系统》
  - 《AI 应用的生产级架构：可观测、成本、安全》
- [ ] GitHub 主页整理：置顶项目 + 清晰 README + Star 截图

## 第 11 周 面试冲刺

- [ ] 刷 [[面试准备]] 高频题，覆盖：
  - LLM 概念、Prompt、RAG、Agent、微调、MCP
  - 系统设计：设计一个智能客服 / 知识库问答 / Agent 平台
  - 领导力题：技术选型、团队搭建、项目排期、风险控制
- [ ] 每天 1 道系统设计题，白板/文档里画架构图讲一遍
- [ ] 模拟面试 3 次以上（真人或 AI 语音对话）

## 第 12 周 求职投递

### 渠道优先级
1. 内推（脉脉、熟人）—— 转化率最高
2. BOSS直聘 / 猎聘 —— 主动打招呼模板要准备
3. 技术社区曝光（博客、GitHub、掘金）—— 让岗位来找你
4. 猎头 —— 挂简历被动等

### 目标岗位关键词
`AI应用开发` `AI工程师` `LLM` `大模型应用` `RAG` `智能体 Agent` `AI平台` `AIGC`

### 每日 SOP
- 早上：投递 10+ 岗位（匹配度优先）
- 下午：继续刷题 + 练系统设计
- 晚上：复盘当天面试 + 更新打卡

### 沟通模板（打招呼）
```
您好，我有 X 年 Java 开发经验，近 3 个月全职转型 AI 应用开发，
已完成企业级 RAG 问答系统和多智能体项目（附演示地址）。
熟悉 Spring AI / LangChain4j / Agent / MCP，能独立设计 AI 系统架构。
看到贵司在招 AI 应用开发，希望有机会聊聊。
```

## 验收标准
- [ ] 简历投出去，每周至少 3 个面试
- [ ] 能完整讲 15 分钟项目 + 30 分钟架构题
- [ ] 目标：4-8 周内拿到 offer（AI 应用开发工程师/负责人）
