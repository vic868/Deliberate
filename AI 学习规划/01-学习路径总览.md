# 学习路径总览（12 周）

> 目标：12 周后具备「AI 应用开发负责人」的硬技能与简历，开始求职。

## 阶段一 基础入门（第 1 周）

**目的**：扫清认知障碍，能独立调通 LLM API。

### 周一~二 概念扫盲（每天 2-3 小时）
- [ ] 看 1-2 篇 LLM 科普：Transformer、Token、Context Window、Temperature、Top-p、幻觉
- [ ] 理解"预训练 vs 微调 vs 提示工程"的区别，知道它们各自解决什么问题
- [ ] 写一篇自己的笔记到 Obsidian（用自己的话复述，才算学会）

### 周三~五 Prompt Engineering
- [ ] 学会结构化 Prompt：角色、上下文、约束、示例（Few-shot）、CoT（思维链）
- [ ] 实操：用 DeepSeek/OpenAI/Claude 免费额度做 20 个 Prompt 实验，记录规律
- [ ] 了解 Function Calling / Tool Calling 是什么（阶段二会用）

### 周末 API 工程实战
- [ ] 用任意语言（Python 最快）调通：对话、流式输出、多轮、Function Calling
- [ ] 了解 Token 计费与上下文窗口管理（截断、摘要）
- [ ] **产出：一个命令行聊天机器人，能流式输出、能算 Token 成本**

## 阶段二 Java + AI 开发（第 2-4 周）

**目的**：把 AI 能力接进 Java 工程，完成企业级 RAG 应用。

### 第 2 周 框架入门
- [ ] 学 LangChain4j（Java 版 LangChain）
- [ ] 学 Spring AI（Spring 官方，重点）
- [ ] 对比两者的定位，选一个为主
- [ ] **产出：Spring Boot + LLM 聊天接口（流式输出，WebSocket/SSE）**

### 第 3 周 RAG 核心
- [ ] Embedding 概念与向量数据库：pgvector、Milvus、Chroma 选型
- [ ] 文档加载 → 切分（chunking）→ 向量化 → 检索 → 注入 Prompt → 回答
- [ ] **产出：基于本地文档的 RAG 问答系统（支持 PDF/Markdown）**

### 第 4 周 RAG 进阶
- [ ] 检索优化：重排序（Rerank）、混合检索（关键词+向量）、多路召回
- [ ] 评估：怎么判断 RAG 答得好不好（检索召回率、答案准确率）
- [ ] 防幻觉：引用溯源、拒答策略、知识库更新机制
- [ ] **产出：把 RAG 打磨成可演示的完整系统 + 写一篇架构笔记**

## 阶段三 高级架构（第 5-8 周）

**目的**：从"会调 API"升级到"能设计系统、带团队"。

### 第 5 周 Agent 开发
- [ ] Agent 原理：规划、工具调用、记忆、反思（ReAct、Plan-and-Execute）
- [ ] 用 LangChain4j / Spring AI 实现带工具的 Agent
- [ ] 了解 MCP（Model Context Protocol），理解 Agent 生态方向
- [ ] **产出：能自主调用多个工具的 Agent**

### 第 6 周 Agent 进阶 + 多模态
- [ ] 多 Agent 协作、人机协同（Human-in-the-loop）
- [ ] 语音、图片、视频：多模态 API 接入
- [ ] 了解最新 Agent 模式（阅读 2-3 篇前沿文章即可）
- [ ] **产出：一个多模态 Agent 功能模块**

### 第 7 周 企业级架构与工程化
- [ ] 生产级要素：可观测性（Trace/日志）、评估体系、成本控制、安全合规、模型降级兜底
- [ ] AI 网关与模型统一接入（多模型切换、限流、熔断）
- [ ] 数据飞轮：用户反馈 → 数据 → 持续优化
- [ ] **产出：写一份《企业级 AI 应用架构方案》文档（面试直接能讲）**

### 第 8 周 技术领导力
- [ ] 系统设计：从需求到落地的完整 AI 项目设计方案
- [ ] 团队视角：人力分工、技术选型决策、风险控制
- [ ] 读 2-3 篇 AI 落地案例（金融、电商、医疗），积累讲故事的素材
- [ ] **产出：一个完整项目的「技术方案 + 排期 + 团队分工」PPT 大纲**

## 阶段四 项目与求职（第 9-12 周）

**目的**：把能力变成 offer。

### 第 9 周 项目打磨
- [ ] 选定 2-3 个代表作（见 [[实战项目]]），把代码、文档、演示视频做完整
- [ ] 项目 README 写清：背景、架构图、技术亮点、业务价值、量化指标
- [ ] 部署上线（免费云/自建），确保能线上演示

### 第 10 周 简历与作品集
- [ ] 重写简历：突出 AI 项目、架构设计、量化成果
- [ ] 准备自我介绍（1 分钟版 + 3 分钟版）
- [ ] 整理技术博客 2-3 篇（RAG、Agent、架构）作为加分项

### 第 11 周 面试冲刺
- [ ] 刷高频面试题（见 [[面试准备]]）
- [ ] 系统设计题演练：白板讲清一个 AI 系统
- [ ] 模拟面试（找 AI 语音或真人互相练）

### 第 12 周 求职投递
- [ ] 渠道：BOSS直聘、猎聘、脉脉、内推、开源社区曝光
- [ ] 目标岗位关键词：AI应用开发、AI工程师、LLM工程师、RAG、智能体
- [ ] 每天投递 10+，坚持复盘面试
