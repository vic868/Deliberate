# 阶段三 高级架构（第 5-8 周）

> 从"会调 API"升级到"能设计系统、能带团队、能做技术决策"。
> 这 4 周是让你配得上"总监/技术负责人"title 的关键。

## 第 5 周 Agent 开发

### 原理
```
Agent = LLM(规划) + 工具(执行) + 记忆(上下文) + 反思(纠错)

常见模式：
- ReAct：边想边做（Reason + Act）
- Plan-and-Execute：先定计划再逐步执行
- Multi-Agent：多个角色 Agent 协作
```

### 学习目标
- [ ] 用 Spring AI / LangChain4j 实现带工具的 Agent（Search、API 调用、DB 查询）
- [ ] 记忆机制：短期（会话）/ 长期（向量库/文件）
- [ ] 理解 Agent 的失败模式：死循环、错误工具、幻觉指令
- [ ] 了解 **MCP（Model Context Protocol）**——Agent 接入外部工具/数据的标准协议，2025 后的主流方向

### 交付
- 一个"能自主完成多步任务"的 Agent 应用（如：让 Agent 查数据 → 分析 → 生成报表）

## 第 6 周 Agent 进阶 + 多模态

### 学习目标
- [ ] 多 Agent 协作：规划者 / 执行者 / 审查者角色分工
- [ ] Human-in-the-loop：关键动作需要人工确认（生产必备）
- [ ] 多模态：视觉理解（读图/截图）、语音（ASR/TTS）、文生图/视频
- [ ] Agent 现状前沿：读 2-3 篇 2025-2026 的 Agent 文章，记下趋势关键词

### 交付
- 给 Agent 增加"读截图/图片"能力，做一个多模态 Agent 功能模块

## 第 7 周 企业级架构与工程化

### 必须掌握的生产级要素（总监级知识）

| 维度 | 关键点 |
| --- | --- |
| 可观测性 | LLM 调用链路 Trace（输入/输出/Token/成本/延迟），建议 Langfuse / OpenTelemetry |
| 评估体系 | 离线评估集 + 线上 A/B + 用户反馈回流 |
| 成本控制 | 模型分层（便宜的干简单活）、缓存、上下文压缩、按量预警 |
| 稳定性 | 模型降级兜底（主模型挂了切备选）、超时、重试、限流、熔断 |
| 安全合规 | Prompt 注入防护、敏感信息过滤、数据脱敏、内容审核、私有化部署 |
| 模型接入 | AI 网关统一接入多家模型（可切换、可灰度）、配置化管理 |
| 数据飞轮 | 用户反馈 → 数据标注 → 评估集扩充 → 持续优化闭环 |

### 学习目标
- [ ] 给 RAG/Agent 加日志 + Trace，跑通可观测性
- [ ] 设计模型分层路由 + 降级方案
- [ ] 实现 Prompt 注入防护与输入输出过滤

### 交付
- 写一份 **《企业级 AI 应用架构方案》**（文档）：
  - 系统架构图、模型选型、RAG/Agent 设计、可观测性、成本、安全、上线规划
