# 阶段三 高级架构（2.5 周）

> [!quote] 本阶段目标
> 从"会调 API"升级到"能设计系统、能带团队、能做技术决策"。**这是配得上"总监"的关键。**

## Agent 原理图

```mermaid
flowchart TB
    U[用户] --> A[LLM 规划]
    A -->|调用工具| T[工具<br>查库/查API/搜索]
    T --> A
    A --> M[记忆<br>短期+长期]
    A --> R[反思纠错]
    R --> A
    A -->|输出| U
    H[人工审批<br>Human-in-the-loop] -.敏感操作.-> A
```

## Week 3 · Agent 开发

> [!example] 交付：能自主完成多步任务的 Agent（查数据→分析→生成报表）

- [ ] ReAct / Plan-and-Execute 模式
- [ ] 工具调用：Search / API / DB 查询
- [ ] 记忆机制：短期（会话）/ 长期（向量库）
- [ ] 失败模式：死循环、错误工具、幻觉指令
- [ ] 了解 **MCP（Model Context Protocol）**

> [!tip] MCP 是 2025 后的主流方向，面试加分点，务必能讲 1 分钟。

## Week 3.5 · 多模态 + 工程化

- [ ] Agent 读图（视觉理解）
- [ ] 可观测性：LLM Trace（输入/输出/Token/成本）

- [ ] 成本控制：模型分层 + 缓存 + 压缩
