## 项目一：企业知识库 RAG 问答系统（必做）

> [!example] 状态跟踪
> - [ ] Spring AI + pgvector 核心跑通
> - [ ] 混合检索 + Rerank
> - [ ] 30+ 测试集评估
> - [ ] 部署上线
> - [ ] 演示视频

- **技术**：Spring Boot + Spring AI + pgvector + bge-m3 + bge-reranker + SSE
- **亮点**：
  - 混合检索（向量 + BM25）+ Rerank，准确率量化提升
  - 30+ 测试集评估：召回率 / 准确率 / 引用正确率
  - 防幻觉：置信度阈值 + 引用溯源
- **面试讲法**：为什么 RAG 不微调 / chunk 怎么切 / 怎么评估优化

## 项目二：智能客服 Agent（必做）

> [!example] 状态跟踪
> - [ ] Function Calling 工具接入
> - [ ] 多 Agent 协作
> - [ ] Human-in-the-loop 审批
> - [ ] 记忆机制
> - [ ] 演示视频

- **技术**：Spring Boot + LangChain4j + Function Calling + 多 Agent
- **亮点**：自主规划（查订单→查物流→回答）、敏感操作人工审批、可观测 Trace
- **面试讲法**：怎么防死循环 / 怎么不乱调工具 / 敏感操作怎么控

## 项目三：AI 数据分析助手（可选加分）

- 自然语言 → SQL → 数据 → 图表 → 文字解读
- 亮点：Text-to-SQL 优化、只读权限、大表 limit 防护
- 适合投"数据分析 / 大模型平台"方向补充
