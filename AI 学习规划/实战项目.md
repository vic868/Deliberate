> 简历上用 2-3 个代表作。每个项目必须有：背景 / 架构图 / 亮点 / 量化指标 / 演示。
> 原则：**宁少勿滥，每个都能讲 15 分钟**。

## 项目一：企业知识库 RAG 问答系统（阶段二 · 必做）

- **背景**：企业文档散乱，员工查资料难 → 用 AI 做企业知识问答
- **技术**：Spring Boot + Spring AI + pgvector + bge-m3 + bge-reranker + SSE
- **功能**：PDF/MD 上传、切片入库、混合检索、Rerank、引用溯源、拒答、权限隔离
- **亮点**：
  - 混合检索（向量 + BM25）+ Rerank，准确率量化提升
  - 建立 50+ 测试集评估：召回率 / 准确率 / 引用正确率
  - 防幻觉：置信度阈值 + 引用溯源
- **量化指标（示例，需自测真实数据）**：
  - 检索命中率 85% → 93%
  - 引用正确率 90%+
- **部署**：云服务器，线上可演示
- **面试讲法**：为什么 RAG 不微调 / chunk 怎么切 / 怎么评估优化

## 项目二：智能客服 Agent（阶段三 · 必做）

- **背景**：客服人工成本高 → 用 Agent 自主处理咨询并调用后台系统
- **技术**：Spring Boot + LangChain4j + Function Calling + 多 Agent + 记忆
- **功能**：
  - Agent 自主规划：查订单 → 查物流 → 回答 / 发起退款
  - 工具调用：对接订单系统 API、用户库
  - Human-in-the-loop：退款等敏感操作人工审批
  - 会话记忆：短期 + 长期（向量库）
- **亮点**：多 Agent 协作（意图识别 → 执行 → 审查）、可观测性（Trace）、降级兜底
- **量化指标**：能自主解决 X% 常见咨询、人工介入率下降
- **面试讲法**：Agent 怎么避免死循环 / 怎么保证不乱调用工具 / 敏感操作怎么控

## 项目三：AI 智能报表 / 数据分析助手（可选加分）

- **背景**：业务要数据，得等开发写报表 → 让 AI 用自然语言查数
- **技术**：Spring AI + Text-to-SQL + 工具调用 + 多模态图表
- **功能**：自然语言 → SQL → 数据 → 图表（柱状/折线）→ 文字解读
- **亮点**：Text-to-SQL 正确率优化、只读权限防篡改、大表 limit 防炸
- **面试讲法**：Text-to-SQL 的坑（表结构复杂、权限、幻觉 SQL）

## 项目四：多模态助手（可选）

- 读图：用户上传截图 → 视觉理解 → 操作建议
- 语音：ASR → Agent 处理 → TTS 播报
- 适合投"多模态 / AIGC"方向的岗位补充
