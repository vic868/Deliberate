# 12 周 AI 应用开发路线

> [!abstract] 目标
> 面向已有 Java 基础的开发者，逐步完成 LLM 基础、Spring AI 服务、企业级 RAG、受控 Agent 和工程化求职材料。每天约 5 小时、每周学习 6 天；安排是学习目标，不是就业结果保证。

## 使用方法

1. 先读 [[01-路线总览]]，按周推进；周内可以根据实际进度调整，不以打卡数量替代掌握程度。
2. 每天复制 [[06-每日学习模板]] 记录实际投入、代码产出和阻塞点。
3. 学到新概念时补充 [[03-专题地图]]；优先写“自己的解释、代码验证、常见错误”。
4. 所有阶段产出汇总到 [[04-项目实践手册]]，避免只有零散练习。
5. 每周用 [[05-RAG评测与复盘]] 的方法记录效果和问题；非 RAG 阶段也可复用“预期—实际—原因—改进”的复盘格式。

## 知识库维护约定

- 每个概念优先说明：是什么、解决什么问题、何时适用、局限、最小代码/例子。
- 记录版本、日期和来源；框架 API、模型能力、价格等可能变化的内容注明核对时间。
- 项目数据、密钥和真实用户信息使用脱敏或合成数据。
- 验收标准以可运行的代码、可重复的评测和能解释的设计决策为准。
