# 专题地图

本页是索引。先链接已有笔记；确有内容缺口时，再在本目录创建专题笔记，避免重复维护。

## 1. Python 与模型基础（第 1 周）

- Python：变量、函数、类、异常、虚拟环境、依赖管理、文件与 JSON 处理。
- LLM 概念：[[../Transformer 面试题/00-Transformer入门总览|Transformer 入门总览]]、Token、Embedding、Attention、上下文窗口、生成参数。
- API 基础：鉴权、请求/响应、超时、限流、重试、流式协议、结构化输出。
- 建议补充：
  - [[专题-Python与模型API基础]]

## 2. Spring AI（第 3–4 周）

- ChatClient、Prompt 模板、系统与用户消息、对话记忆、结构化输出。
- Tool Calling、流式输出、模型配置、错误映射和服务边界。
- Spring Boot 工程：REST、参数校验、统一异常处理、日志、配置管理和测试。
- 建议补充：
  - [[专题-SpringAI应用服务]]

## 3. RAG（第 5–8 周）

- 摄取：解析、清洗、分块、元数据、文档版本和异步任务状态。
- 表示与索引：Embedding、向量库、索引重建、更新和删除。
- 检索：向量检索、关键词检索、混合检索、元数据过滤、Top-K、Rerank。
- 生成：上下文组装、引用、拒答、Prompt 注入边界。
- 评估：检索命中、上下文相关性、答案正确性、引用正确性、延迟和成本。
- 建议补充：
  - [[专题-RAG端到端设计]]
  - [[05-RAG评测与复盘]]

## 4. Agent、工具与 MCP（第 9–10 周）

- 明确 Agent 与确定性工作流的边界；不是所有多步任务都需要 Agent。
- 工具契约：输入 Schema、权限、只读/写入、幂等键、超时、错误类别和审计。
- 工作流：状态持久化、人工确认、恢复、补偿和循环上限。
- MCP：理解客户端、服务端、工具/资源/提示等概念；先做小型本地示例。
- 建议补充：
  - [[专题-Agent工具与工作流安全]]

## 5. 工程化与求职（第 11–12 周）

- 自动化测试：单元测试、契约测试、模型调用替身、评测回归。
- 可观测性：请求 ID、模型/提示版本、工具调用、检索结果摘要、延迟和错误；避免记录敏感原文。
- 部署：Docker、环境配置、健康检查、资源限制、启动文档。
- 质量：故障注入、性能基线、成本估算、降级与限流。
- 求职材料：架构图、接口说明、演示流程、决策记录、面试问题。
- 建议补充：
  - [[专题-AI应用工程化与交付]]
  - [[../面试准备|现有面试准备笔记]]

## 笔记完成标准

每篇专题笔记至少包含：一句话定义、解决的问题、核心流程/图、最小可运行例子或伪代码、常见失败、如何验证、适用边界、来源和最后核对日期。
